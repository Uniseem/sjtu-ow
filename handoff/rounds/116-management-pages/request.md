# 116 前台管理页：复查第二部分（成员这边）

## 背景

115 轮的复查（`handoff/rounds/115-admin-review/findings.md`）第二部分「应该修」里，成员在前台用到的几条，加上第三部分第 28 条前台和设计体系不一致的地方。

## 本轮范围

1. **战队管理页**（#12、#14）：成员表加「位置与段位」；入队申请列出每个游戏 ID 和它的段位；解散的条件提前写出来、按钮置灰；空的申请列表用 `c-empty`；列表一次取出游戏 ID
2. **创建战队**（#14）：没有权限、队长数到上限的，打开页面就说明、不给表单；建队失败时把先存的队标删掉；队名重复写在队名那一栏下面（管理页同样）
3. **报名**（#13）：报名详情的名单快照加「段位（提交时）」；后台报名详情的段位写成「钻石 3」
4. **我的报名**（#18）：只列我现在还在名单上的报名（设计 13.5「有效」）；个人报名加游戏 ID 列、按钮写「取消个人报名」、已结束和已取消的赛事不再显示「等待编队」；两个空列表用 `c-empty`
5. **账号页**（#15、#19）：改密码、改邮箱、邮箱地址、设置密码四页加「个人中心 / 账号安全」的位置导航；「账号安全」加退出登录；导出个人信息的链接去掉 `download`，改用加载条认的 `data-no-loading`（超出频率时提示不再丢）
6. **注册页**（#16）：两个同意框下面链到用户协议、隐私政策（新标签页）；删掉设计文档口吻的那句话
7. **说法统一**（#17）：内战被禁止时用 4.3.2 的标准说法；个人报名的问题对本人说「你」，不再叫本人的昵称；资料不完整的提示下面给出去补全的链接（内战、个人报名、申请入队）
8. **评论**（#20）：发太快、太长被拒时，输入框和打的字都留着；只有没有评论权限时才不显示输入框
9. **我的战队**（#28）：两个空列表用 `c-empty`；模板里组件不认的参数（`index=`、`en=`）删掉

**不做**：内战报名出错只显示几秒的提示、选的游戏 ID 和位置丢失（要把报名表改成就地显示错误，量比较大，放到后面）；入队申请表的位置提示（缺的位置排前、标「缺」）。

## 验证

每条有测试，变异逐条改坏；本机截图看战队管理页、我的报名、账号安全。

## 验收标准

`AGENTS.md`「常用命令」那组全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
