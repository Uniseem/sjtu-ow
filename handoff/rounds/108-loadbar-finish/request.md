# 108 加载条走满再淡出

## 背景

106 的加载条：等新页面时出现、先快后慢地往前走；新页面到了，旧页上那条停在半路的条随旧页一起淡掉。用户 2026-10-03：

> 这个条逻辑有点问题，最后加载完了应该要很顺畅地非线性走满然后淡化消失，这样才是完整流畅的

## 本轮范围

**做**（先改设计 13.2.4，记 v6.6）：

1. 旧页离开时记下加载条走到了哪里（只记真正出现过的条：点击 150ms 后才记），存在这个标签页的 `sessionStorage` 里
2. 新页面在第一次绘制之前读出来（`<head>` 里的小脚本 `static/js/arrival.js`；被提前准备的页面等真正显示时再读），给 `<html>` 加 `is-arriving`：加载条从旧页停下的位置 300ms 先快后慢地走满，再 250ms 淡出。不靠跨页面过渡，Firefox 一样
3. 没出现过的条（页面 150ms 内就到、提前准备好的页面）不记，新页面不会凭空冒出一条
4. 记录 20 秒后作废；开始新的一次加载时清掉旧记录
5. 减少动态效果时：不走满，直接消失

**不做**：别的。

## 验证

测试：样式（走满、淡出、时长和曲线）、`arrival.js`（读、删、20 秒作废、被提前准备的页面等显示）、`loading.js`（150ms 后才记、离开时记位置、开始时清旧记录、停止时清记录）、`base.html` 在 `<head>` 里引入 `arrival.js`；变异逐条改坏。无头 Edge：带着记录换页，新页面上加载条从记下的位置走满再淡出，截图。
