# 134 没编进队伍的散人也收到开赛提醒

## 背景

继续用户 2026-10-04 睡前的要求（假定各种身份走流程）。赛事默认是个人报名（用户 10-03 定的）：每人自己报名进散人池，赛事管理员编成临时队伍，编进去就算通过。129 的开赛提醒只发给已通过名单里的人。以散人的身份：管理员编完队，我没被编进去，到开赛什么也收不到，「我的报名」里一直是「等待编队」，不知道是还在编还是这次落空了。

另外，129 之后才被编进队伍的人（提醒已经发过）只收到「已编入临时队伍」，那封信不写比赛时间。

## 本轮范围

1. 开赛提醒到时，如果编队已经开始（有已通过的临时队伍，也就是 129 那批提醒至少发出一封），散人池里还没编进的人各收一封「赛事提醒」：还在散人池里、编进时会另外收到邮件、到开赛还没编进可能这次没有位置
2. 一个队都没编时不发，也不记为已发送（和 129 一致）
3. 「已编入临时队伍」的信写比赛时间
4. 邮件样张页加这封；设计 8.1、10.2（v6.29）；README

## 不做

- 管理员编完队后点一个「编队完成」通知落选的人：没有「完成」这个时刻，管理员随时会调；提醒时的状态已经够用

## 验证

测试：编了一队、池里剩一人时，两人收到队伍提醒、一人收到散人提醒；一队都没编时谁也不发、不记为已发送；停用账号不发；编入信写时间；样张页。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
