# 026 附录 C 参数逐条核查

设计附录 C 是一张 60 多行的「默认参数汇总」表，每一行写明参数、默认值、以及改在哪（后台 / 配置 / cron）。

**没有任何东西保证代码里的值和这张表一致。** 023 核查的是第 15 章的要求，这轮核查的是附录 C 的数字。

## 任务

### T1 逐条比对

把表里能对应到代码的每一行，实际取值打出来和文档比。

### T2 写成测试

对上的写成断言，让以后改坏了会红。分三组：`settings` 常量、代码常量、`SiteSettings` 的默认值。

### T3 对不上的修掉

## 验收标准

1. `ruff` / `pytest` / `makemigrations --check` / 生产 `check --deploy` 全部干净
2. 贴出逐条比对的结果
