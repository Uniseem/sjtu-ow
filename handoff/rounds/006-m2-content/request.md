# 006 M2 第一部分：内容页面与分享信息

## 背景

M1 已完成（005 复核通过）。M2 内容很多，拆成五轮：

| 轮次 | 内容 |
|---|---|
| **006（本轮）** | 页面类型、文章分类、首页、文章列表与详情、页面元信息 / sitemap / robots |
| 007 | 投稿：投稿者组同步、后台定制、审核工作流、前台投稿入口 |
| 008 | 字体库与排版设置 |
| 009 | 半静态渲染机制 |
| 010 | AI 内容审核 |

设计依据：`docs/design.md` v1.5.3，重点读 5.1–5.3、12.5、13.4、13.14 节。

## 本轮范围

**做**：T1–T5。
**不做**：投稿（007）、字体库与排版（008）、预渲染（009）、AI 审核（010）、战队 / 赛事 / 内战 / 开放 API。

## 任务

### T1 页面类型（设计 5.1、5.2、12.5.1）

1. `HomePage`（全站唯一）、`ArticleIndexPage`、`ArticlePage`、`StandardPage`
2. `ArticlePage` 的字段按 12.5.1 节：分类、封面、摘要、正文 StreamField、作者、关联赛事。**关联赛事字段本轮先不加**（Tournament 模型还不存在），在模型里写清楚注释说明 M4 补，不要建假的外键
3. 正文 StreamField 的块按 5.2 节：段落（富文本，限制为二三级标题、加粗、斜体、列表、链接）、图片 + 图注、引用、视频嵌入
   - 视频嵌入：确认 Wagtail 自带的嵌入提供方是否支持 B 站，**把确认结果写进报告**；不支持就先只支持它自带的提供方，B 站的自定义嵌入规则留到有需求时再做
4. `HomePage` 的置顶文章用可排序子表（最多 3 篇）

### T2 文章分类（设计 5.3、12.5.2）

1. `ArticleCategory` snippet：名称、网址片段、排序、是否开放投稿
2. `init_site` 创建初始分类：公告（不开放投稿）、赛事通知（不开放投稿）、攻略、战报、心得
   - 这几个分类是设计第 19 章待定问题 4 的建议值，先按这个建，后面社团要改可以在后台直接改

### T3 前台页面（设计 5.2、13.4）

1. 首页四个区块按 5.2 节：最新公告（或置顶文章）、正在报名的赛事、近期内战、组队大厅入口
   - 赛事和内战模型还不存在：这两个区块本轮渲染成「即将开放」的占位块，**在模板里留好数据入口**，M4 / M6 接上时只改视图不改布局
   - 组队大厅入口按 5.2 节：未登录显示「登录后查看」，登录显示车帖数量——车帖模型也还没有，本轮先显示「登录后查看」，并注明 M3 接入
2. 文章列表：按发布时间倒序，每页 12 篇，可以按分类筛选（查询参数）
3. 文章详情：标题、分类、作者昵称、发布时间、封面、正文
4. 普通页面：用户协议、隐私政策等
5. 所有页面移动端可用，不能出现内联 style，控制台 0 报错

### T4 页面元信息与分享（设计 13.14）

1. 每个页面输出 `<title>`、`<meta name="description">`、`<link rel="canonical">`
2. Open Graph 元信息按 13.14 节的表格（文章、普通页面用站点简介和默认分享图；赛事、战队、内战的分支先留好扩展点）
3. 站点简介和默认分享图读 `SiteSettings`（字段 M1 已经建好）
4. `/sitemap.xml`：列出公开的文章和普通页面（赛事、战队、内战等后续里程碑补充）
5. `/robots.txt`：禁止抓取 `/admin/`、`/api/`、`/me/`、`/accounts/`、`/_fragments/`

### T5 顺带修（005 复核的建议）

`init_site` 处理 Wagtail 自带的 `Editors` 和 `Moderators` 两个组：删掉，或改名成不会和「内容编辑」混淆的名字。选哪种在报告里说明。

## 测试要求

至少覆盖：文章列表分页和分类筛选、文章详情可访问、未发布的文章前台不可见、置顶文章最多 3 篇、分类的「开放投稿」标记、页面元信息和 Open Graph 的内容、sitemap 只包含已发布页面、robots.txt 的禁止规则、`init_site` 仍然幂等。

## 验收标准

逐条实际执行，输出贴进 `report.md`：

1. `ruff` / `pytest` / `makemigrations --check` / 生产配置 `check --deploy`
2. 后台新建一篇文章并发布，前台列表和详情都能看到（贴关键输出或截图）
3. 撤回发布后前台返回 404
4. 浏览器打开首页、文章列表、文章详情（桌面 + 375px）：0 条控制台报错（贴截图）
5. `curl` 文章详情页，贴出 `<title>`、`description`、`og:*`、`canonical` 五行
6. `curl /sitemap.xml` 和 `/robots.txt`，贴出内容
7. 回归：`/me/` 四个页面仍然正常；注册登录流程仍然正常；`/healthz` 在 worker 运行时 200
8. `docker build` 成功、`caddy validate` 通过
9. git 提交，信息以 `006:` 开头
