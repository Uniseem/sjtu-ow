# 117 后台的文字和菜单：复查第二、三部分（后台这边，一）

## 背景

115 轮的复查（`handoff/rounds/115-admin-review/findings.md`）里，后台还剩第 21、22、24、25、26、27、29 条和「其他（小）」、第四部分「文档和实现对不上」。分两轮做：这一轮是**看得见的文字和菜单**（第 22、26、27 条和第四部分），下一轮（118）是后台功能（首页待办、内容审核、分队页、停用标记等）。

## 本轮范围

1. **后台的英文**（#26）：Wagtail 8 的中文翻译缺一百多条（帮助菜单的「Shortcuts」和快捷键说明、首页的「26 Pages」「Search all pages…」、报告「Page types usage」、空列表「There are no … to display」、列表排序提示、编辑页右侧的「Checks」和内容指标、帐号页的主题设置等）。用项目自己的翻译补上：`locale/zh_Hans/LC_MESSAGES/django.po`、`djangojs.po`，设置 `LOCALE_PATHS`。原文按页面实际查过翻译的字符串记下来（逐页渲染时记录查不到译文的原文），不靠猜。不装 gettext：新命令 `compile_translations` 用标准库把 `.po` 编成 `.mo`，两种文件都提交；测试检查 `.mo` 和 `.po` 一致、几个页面不再出现这些英文
2. **布尔值**（#22）：文章分类的「开放投稿」、成员分组的「显示」、用户功能规则的「允许」，列表里从 `True`/`False` 换成勾和叉（Wagtail 的 `BooleanColumn`，评论和战队已经这样）
3. **静态页面列表**（#22）：类型从英文代码（`article`、`team_index`）换成中文；分页（每页 50 条）；按状态筛选（全部、生成失败、等待生成、已生成）
4. **菜单**（#27，设计 14.1）：
   - 「内战」改「内战活动」
   - 顺序：页面、图片、社区、成员分组、文章分类、用户、报告、设置、帮助；社区下面：赛事、报名审核、内战活动、战队、内容审核、头像审核、评论
   - 「用户」单独一个菜单（用户、用户组、功能权限），从「设置」里移出来
   - 「报告」「帮助」只给超级管理员和内容编辑（现在赛事管理员、内战管理员、认证作者也有）
   - 关掉 Wagtail 首页的升级提示（`WAGTAIL_ENABLE_UPDATE_CHECK`）：升级是开发者的事，提示对管理员没用，还会让浏览器去访问 Wagtail 的服务器
5. **页面树里看到别人的草稿**：查菜单时发现，赛事管理员、内战管理员验证过邮箱后也在「投稿者」组，能打开页面树，但「只看已发布的和自己的稿件」这条过滤（14.3）只对纯投稿者生效，他们能看到别人还没发布的稿件标题。改成：不是超级管理员、内容编辑、认证作者的，页面树都按投稿者过滤（先复现再改）
6. **设计文档对齐**（第四部分）：13.4 路由表补全（成员详情、内战报名、撤回报名、战队的 POST 地址、游戏 ID 和联系方式的编辑删除、邮件样张）；14.1 改成实际的菜单和可见角色（认证作者要用页面和图片、赛事管理员要用图片选封面、设置里 Wagtail 自带的几项）；13.2.7 次要按钮的名字（`--quiet`，还有 `--tonal`）；12.4.1 补备份的几个字段。附录 D 记 v6.13

**不做**（下一轮）：后台首页待办、内容审核的时间筛选和全量扫描、分队页复制按钮、名单上的「账号已停用」、自定义页面写法统一（#29）、操作记录。
