# 088 赛场与名册按 v4.0 重做：赛事、内战、战队、成员

## 背景

M10 第三轮。设计 13.2.7 的「赛场列表」「赛场详情」「名册」三种骨架。这些页现在是 v3 版式（色调区块页头、票根、名额格、图块墙、数字统计条）加 v4 颜色。

## 本轮范围

**做**：

1. 赛事列表：栏目头只有标题和一句话；报名中、即将开始的用赛事图片卡（`components/tournament_card.html`：封面或灰底写赛事名、状态和关键日期、标题、「N–M 人一队 · 已通过 N 队」），其余用表格
2. 内战列表：即将开始的用列表行（`components/scrim_row.html`：日期块、标题、时间 · 规格 · 已报、进度条、状态），最近结束的用表格
3. 战队列表：`c-teams` 网格（`team_tile.html` 改写），筛选改下划线式；创建战队按钮在栏目头
4. 详情页（赛事、内战、战队）：`c-stage` 横幅（赛事有封面时是大图，内战和战队是实色条）写面包屑、状态、标题、一行事实；报名 / 申请加入放在横幅下面的 `c-panel`；侧栏资料表放进 `c-panel`；赛事的相关文章改列表行
5. 成员展示：去掉数量徽标和「按加入先后」小字，保留 001 起的编号（设计 6.3）
6. 删掉 v3 的票根、名额格、图块墙、色调区块、数字统计条样式和 `tournament_ticket`、`scrim_ticket`、`slots` 三个组件，`slot_cells`、`percent_of` 两个过滤器一起删；文章页的关联赛事改用赛事图片卡
7. 设计 13.2.6 补 `c-stage`，13.6 模板目录更新

**不做**：个人中心、表单、评论、错误页（089）。

## 验证

- 列表页的栏目头里没有统计条、全站赛场页没有数量徽标
- 报名中 / 即将开始是图片卡、其余是表格；图片卡只数通过的队伍
- 横幅里没有操作，操作在下面的面板里；资料表在面板里
- 战队列表不因为每支队多查一次数据库
- 变异（先跑基线）；截图浅色、深色、375
