# 125 成员找到并整理自己的主页

## 背景

用户（2026-10-04 睡前）的走查清单里有「要展示自己」。以成员身份看：个人主页（6.4，基础版，设计待和用户讨论）上显示什么都在，但**从个人中心去不了自己的主页**，只能去成员展示页里找自己；看自己的主页时也**没有回去改资料的路**，空着的地方（没写宣言、没选位置、没进战队）本人也不知道要去哪儿补。

## 本轮范围

1. 个人中心页头昵称旁「我的主页」
2. 本人看自己的主页：「编辑资料」链到个人中心；没写个人宣言、没选常用位置、没加入战队的地方各一句只给本人看的提示和链接；别人看不到这些
3. 设计 6.4（v6.21）：原来写「个人主页上没有编辑入口」（我在 097 定的），改成不能直接编辑、本人有链接回个人中心

页面的视觉设计照旧等用户讨论，这轮不动版式。

## 验证

测试：个人中心有「我的主页」；本人看到编辑入口和三处提示，别人看不到；填好的地方不出提示。变异逐条改坏。

## 验收标准

`AGENTS.md`「常用命令」那组全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
