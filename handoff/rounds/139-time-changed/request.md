# 139 改了比赛时间要告诉报了名的人

## 背景

继续用户 2026-10-04 睡前的要求（假定各种身份走流程）。以临时改期的赛事管理员身份：比赛推迟，在后台改了比赛时间。按 129 和内战原来的设计，提醒只发一次；如果提醒已经发出，大家手里拿的是旧时间，到点白跑一趟。就算提醒还没发，报了名的人也不知道改了，除非自己回去看。内战一样。

## 本轮范围

1. 已发布的赛事在后台改了比赛时间（原来有时间、新时间不同、新时间还没到）：给报了名的人（有效名单里的人、个人报名过的人，去重）各发一封「比赛时间改了」，写原来和现在的时间；清掉 `reminder_sent_at`，按新时间重新提醒
2. 内战同样：全部报名者收到「内战时间改了」，提醒重新安排
3. 后台编辑页保存时比较保存前后的开始时间（Wagtail 编辑视图的 `form.initial`）
4. 邮件样张页加两封；设计 8.1、9.1、10.2、10.3（v6.34）；README

## 不做

- 第一次填比赛时间不发「改了」：开赛提醒会说
- 改到已经过去的时间不发：多半是事后补录

## 验证

测试：改期后名单里的人收到、信里有原来和现在的时间、提醒标记清掉；时间没变、第一次填、改到过去、草稿都不发；散人收到；驳回的名单不收；在后台编辑页真的改一次时间会发。内战同样。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
