# 187 下拉菜单点别处收起；前台右键菜单

## 背景

用户 10-04（截图里颜色模式菜单和账号菜单同时开着、叠在一起）：「目前有问题，这两个东西点出来之后，点击其他地方也不会自动关闭。然后我希望你全站做一个右键劫持，默认的太难看了」。

页头的颜色模式、账号、手机抽屉三个下拉都是 `<details>`（设计要求不靠脚本也能用），浏览器的 `<details>` 只有再点一次按钮才收起。

## 本轮范围

1. `js/app.js`：三个 `<details>` 下拉点外面、按 Esc、打开另一个时收起，同一时间只开一个；Esc 收起后焦点回到按钮。账号菜单是登录后换进来的区块，用事件委托
2. `js/contextmenu.js` 和样式 `c-ctxmenu`：前台鼠标右键弹出本站菜单，按场合列出链接、图片、选中文字的操作和后退、前进、刷新、复制本页链接、回到顶部；复制成功提示「已复制」；键盘可用（方向键、Enter、Esc）
3. 留口子，不把浏览器的功能弄没：按住 Shift 右键、输入框和可编辑区域里、触屏设备都照用浏览器的菜单；后台不加载
4. 设计 13.2.6、13.3（v6.65）；样张页加右键菜单

## 验证

测试：base 模板加载脚本；右键菜单脚本里的几个口子都在、不用 `innerHTML`；样式只用颜色令牌、字号不小于 14px（现有测试覆盖）；样张页有 `c-ctxmenu`。在本机开发服务器上用内置浏览器真的点开、点外面、按 Esc、右键链接和空白处，看菜单和复制。变异逐条改坏。

## 验收标准

整组检查全绿；变异全部被抓到；浏览器里看过；推送 `main`，CI 绿；正式站升级。
