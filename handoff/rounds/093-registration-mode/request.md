# 093 赛事报名方式二选一；内战详情页头加图

## 背景

092 推送后，用户 2026-10-03 说：

> 所有的比赛都是默认报名，只有管理有发布时指定了整队报名时才会整队报名，且不需要成员确认，队长报了直接整队拉进去。所以你相应的界面要改，然后那个内战上面怎么没有 svg 动图背景呢，空荡荡的不好看。

问了一句「指定了整队报名的赛事，没有战队的人还能不能个人报名」，用户选「不能，只收战队」。所以是**二选一**：

- **个人报名**（默认）：每个人自己报名，赛事管理员编成临时队伍（现在的 8.8 节）。队长也一样个人报名
- **整队报名**：管理员发布前选。只收战队，队长报名后全队直接进名单，不需要队员确认

现在的样子：战队报名一直开着，「开放个人报名」是可选的开关（默认关），两种可以同时开；内战详情页头是素色条（`c-stage--plain`），没有图。

## 本轮范围

**做**（设计 v5.3，先写文档）：

1. 赛事字段「开放个人报名」换成「报名方式」：个人报名（默认）/ 整队报名。已经有报名（战队报名或个人报名）后不能改。迁移把旧数据换过来：开着的是个人报名，关着的是整队报名（旧赛事行为不变）
2. 校验：个人报名的赛事不收战队报名，整队报名的赛事不收个人报名，服务端拦
3. 赛事页：标签和侧栏写报名方式；个人报名的赛事显示散人名单和「已编成的队伍」，整队报名的显示「已通过的战队」；报名入口按方式和身份显示。整队报名的赛事里，不是队长但已经在某个名单里的人看到「你在「队名」的名单里」和「查看报名」
4. 战队报名页：写明提交后全队直接进名单、不需要队员确认；游戏 ID 默认选好
5. 被队长报进名单的队员收到一封邮件（以前只发给队长）：哪支队、哪个赛事、用的哪个游戏 ID、当前状态，不需要确认，不想参加找队长。同步名单时只发给新加进来的人
6. 后台：「报名方式」放在报名规则第一项，「报名自动通过」写明只对整队报名有效；列表筛选换成报名方式；「队伍编排」只在个人报名的赛事出现
7. 内战详情页头：用占位图（按 ID 固定取一张，会动），和没有封面的赛事一样是图片横幅
8. 文档：design 8.1、8.2、8.3、8.8、10.2、12.8、13.2.7 等，design-details 第 8 节，README 赛事一段

**不做**：队员拒绝或退出整队报名（用户说不需要确认；不想参加的找队长同步名单）；同步名单时给被移出的人发信（留给以后）；内战上传封面。

## 验证

| 任务 | 验证 |
|---|---|
| 默认值和迁移 | 测试：新赛事是个人报名；旧开关开 / 关分别换成个人 / 整队 |
| 互斥 | 测试：个人报名的赛事提交战队报名被拒；整队报名的赛事个人报名被拒 |
| 锁定 | 测试：有战队报名或个人报名后后台不能改报名方式；没有时能改 |
| 赛事页入口 | 测试：个人报名赛事里队长看到「个人报名」；整队报名赛事里队长看到「为战队报名」、名单里的队员看到所在队伍、其他人看到「需要由队长为战队报名」 |
| 赛事页内容 | 测试：散人名单只在个人报名赛事出现；标签和侧栏写对方式 |
| 队员邮件 | 测试：首次提交发给名单里除队长外的每个人；同步只发给新加的；个人报名的临时队伍不受影响 |
| 后台 | 测试：编排入口只在个人报名赛事 |
| 内战页头 | 测试：详情页横幅有占位图，不是素色条 |
| 变异 | 上面每条改坏，对应测试要红 |
| 截图 | 两种方式的赛事详情、内战详情，浅色 / 深色 |
