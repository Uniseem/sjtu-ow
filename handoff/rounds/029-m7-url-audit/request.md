# 029 设计里写到的地址逐个核查

026–028 钉住了设计的数字、枚举、段位编码。这轮钉住**地址**。

设计通篇按名字引用这些路径（`/teams/<id>/manage/`、`/me/registrations/`……）。删掉或改名一个路由很容易，而且**不会报 404**——`wagtail_urls` 是 URLconf 末尾的兜底，会接住一切。

## 任务

把设计里写到的每个地址列出来，断言它由**预期的那个 view** 处理（不只是「能解析」），并且公开页面真的能渲染出内容。

## 验收标准

1. `ruff` / `pytest` / `makemigrations --check` / 生产 `check --deploy` 干净
2. 贴出逐个核查结果
3. 变异测试确认测试咬得住
4. git 提交，信息以 `029:` 开头
