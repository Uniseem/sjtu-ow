# 169 每个页面都在真浏览器里打开一遍

## 背景

继续自主推进。168 的 `journey.py` 只走了新人那一条路。后台的拖拽编队、拖拽分队这类脚本多的页面，测试根本跑不了它们的脚本，浏览器里报不报错没人看过。

## 本轮范围

1. `journey.py pages`：遍历项目自己定义的全部地址（和 167 的乱填测试同一份列表，再加首页、资讯、后台首页、页面列表、登录页），以访客、成员、站长三种身份在 Chromium 里打开（后台只用站长），记下浏览器报的错、未捕获的异常、内容安全策略的拦截和 500。只收 POST 的地址返回 405 时浏览器会把自己的错误页记成一次加载失败，这类不算；页面片段（`/_fragments/`）不是给人直接打开的，跳过
2. 扫出来的问题当轮修
3. AGENTS.md 写上这个模式

## 验证

扫一遍、修、再扫到 0；修的问题有测试，变异逐条改坏。

## 验收标准

测试机上整组检查全绿、`journey.py pages` 0 处问题、`journey.py` 全部走通；推送 `main`，CI 绿；演示站升级。
