## 判断里最没把握的

- **路径参数最后写覆盖 JSON**：绑定顺序的写法是防「请求体改路径对象」，但这依赖「path 字段同时也是 json 字段」这种没人会写的组合；真正的防线是 5.5 自动保存协议里 In 不含路径外的 id。记录在案，等 apigen 生成 TS 时把 In 的字段集收紧
- **CrossOriginProtection 的放行面**：无 Origin 无 Sec-Fetch-Site 的请求全部放行（非浏览器口径）。这对 API 正确（curl、微信内置浏览器），意味着「同机另一个进程」也能打写接口——防护靠 SameSite Cookie + 会话只在站内下发的组合，等会话中间件落地后在真浏览器里验一遍
- **Budget 只声明未执行**：查询预算测试还没接上（要等第一个真实页面接口 + Counter 接线），本轮只有选项本身
