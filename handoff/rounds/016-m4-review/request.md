# 016 M4 第三部分：后台报名审核与导出

> 用户外出期间，本轮仍由 Claude 实现 + 自查。M4 最后一轮。

## 背景

014 做完赛事、015 做完报名和状态机（服务层已经覆盖全部状态转换）。本轮把后台审核界面接上。

设计依据：`docs/design.md` v1.5.7，8.7 节，以及 4.1（谁能看联系方式）、14.4（操作记录）。

## 本轮范围

**做**：T1–T5。
**不做**：上游 API（M5）、Webhook（M5）。

## 任务

### T1 审核列表（设计 8.7）

「社区 → 报名审核」，赛事管理员和超级管理员可见：

- 按赛事、状态筛选
- 每行显示战队、人数、状态、提交时间、名单版本
- 默认只看待审核

### T2 审核详情

- 名单快照（昵称、游戏 ID、段位、是否交大）
- **联系方式只对有 `accounts.view_contactmethod` 权限的人显示**
- 战队当前成员与名单的差异（谁多了、谁少了）
- 状态日志（时间、动作、前后状态、操作方、备注）
- 操作：通过、驳回（必填备注）、撤销通过（必填备注）；**按钮只在当前审核模式允许本站操作时显示**

### T3 批量通过

列表里勾选多条，一次通过；逐条走服务层，失败的条目单独提示，不影响其他条目。

### T4 CSV 导出

导出当前筛选结果。包含联系方式时（导出者有权限），在 Wagtail 操作日志里记录是谁、什么时候导出了哪个赛事的数据。

### T5 权限

内容编辑、投稿者、普通用户都进不去；赛事管理员可用。

## 测试要求

至少覆盖：列表筛选、默认只看待审核、详情的名单与差异、联系方式按权限显示、三种审核模式下按钮的显隐、通过 / 驳回 / 撤销、驳回必须填备注、批量通过（含部分失败）、CSV 内容与权限、导出留痕、权限矩阵。
