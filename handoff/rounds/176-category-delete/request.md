# 176 还有文章在用的分类不能删

## 背景

继续自主推进。174 之后接着看 Wagtail 自带的删除会不会撞上本站的规则。全站 6 个 `on_delete=PROTECT` 的外键里，4 个指向用户或战队（后台删不了）、1 个是排版设置引用字体（表单会清掉、删除前也检查）、剩下一个是文章引用分类。

以内容编辑的身份（068 起能管文章分类）在测试机上试：删一个还有文章的分类，删除页写着被引用，点确认：

```
GET 200 说被引用
POST 500 category still: True article still: True
```

服务器错误（`ProtectedError` 没人接）。批量删除一样会撞上。

## 本轮范围

1. 有文章（包括草稿）在用的分类：列表上不显示「删除」；批量删除跳过它；直接打开删除地址时提示「还有 N 篇文章在这个分类里，先把它们改到别的分类再删」并回到编辑页。没有文章的分类照常删
2. 设计 5.3（v6.59）

## 验证

测试：在用的分类列表上没有删除、删除地址给提示不删、批量删除不删；空的分类能删。用内容编辑测（不是超级管理员）。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
