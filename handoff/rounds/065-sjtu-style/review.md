# 065 复核结果

## 结论

**通过，但风格要用户继续看。** 功能、测试、部署都核对过；「像不像交大官网、有没有 AI 味」只能用户判断，本轮三次被否决，这一版用户还没表态。

## 逐项

| 要求 | 结果 |
|---|---|
| 设计先改 | 13.2、5.2、12.5.1、13.3、13.13.4、19.2、附录 D |
| 不用交大校徽、校名书法和照片 | 标志是自己设计的印章样式；图片全部 CC0；页脚写明不是官方网站 |
| 焦点图可维护、有回退 | 测试 + 变异；测试机上 3 张焦点图正常轮播 |
| 轮播符合 CSP | 外部脚本；本地浏览器里 5 秒后自动换到下一张、点圆点能切回，控制台没有报错 |
| 正文样式 bug | 编译后的 CSS 有测试守着 |
| 测试机 | 迁移、重启、20 个静态页由 worker 生成，无失败 |

## 判断里最没把握的

- **风格本身**。用户说「AI 味」的地方我前两次都没看出来；这一版照官网逐块对应，但官网首页的很多「味道」来自真实照片和书法校名，我们都不能用。**以后上了社团自己的活动照片，效果会比示例图更接近**
- **宋体在屏幕上的可读性**：Windows 上的「宋体」小字号偏细，长文章可能累眼。官网本身也是宋体，所以照做；如果反馈不好，后台排版设置可以把正文换成黑体，不用改代码
- **楷体**：Mac 和 Windows 自带，安卓一般没有，会退回正文字体，只剩缩进
- **置顶文章的语义改了**：原来置顶会让最新文章不出现在首页，现在置顶排在前面、后面接最新文章。设计已改，用户没单独确认这一点
- **测试机上的示例内容**：赛事和内战标题看起来像真的（「2026 秋季校内赛」）。页顶有「测试环境」横幅，正文写了「示例」，但如果社团成员看到可能会以为真要比赛。上线前测试机数据会清掉
- 手机上焦点图只有约 160px 高，字幕条占了一半，照片的内容看得不多
