# 065 视觉风格：照上海交大官网

## 背景

设计 19.2 第 8、9 条（视觉风格、深浅色）一直没定，前台用的是 daisyUI 默认主题占位。用户 2026-09-19 看了前台，要一套「又正式又现代」的风格。

过程中用户的决定（按时间）：

1. 想参考 HeroUI 自己设计一套，主色用深红，类似 www.sjtu.edu.cn → 做了三页原型后，用户认为**太不正式**，「不能用 HeroUI，模仿交大网站那个风格」
2. 第一版交大风格的首页（红页头、米色横幅加两个按钮、2×2 区块），用户认为 **AI 味重**；第二版（不对称的门户布局）**AI 味更重**，要求**照交大官网做，包括图片滚动**
3. 文章里的引用（彩色左边框加底色的框）**AI 味重**，要改
4. 示例图片换成网上真实的图片；推送 GitHub，更新测试机

## 任务

1. 设计先改：13.2 节写定风格（交大红、宋体、直角、只做浅色）；5.2 首页区块照官网首页；12.5.1 新增焦点图子表；19.2 第 8、9 条结案；附录 D
2. daisyUI 自定义主题 `sjtu`，关掉内置主题和跟随系统的深色
3. 页头、页脚、首页、资讯列表、文章页、普通页面照官网和交大新闻网改
4. 首页焦点图：后台可维护，没有时回退到带封面的文章；轮播脚本放外部文件（CSP）
5. **不用交大的校徽、书法校名和照片**；页脚写明不是官方网站
6. 测试 + 变异；测试机部署，放一些真实图片（只用 CC0 / 公有领域的）

## 验收标准

本地检查全绿，CI 绿；测试机首页能看到轮播和真实图片。
