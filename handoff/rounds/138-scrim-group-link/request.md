# 138 内战说清楚分队结果发到哪个群

## 背景

继续用户 2026-10-04 睡前的要求（假定各种身份走流程）。以报了内战的成员身份：活动页、提醒邮件都写「分队结果由管理员发到群里」，但没说是哪个群，新成员不一定在社团群里。全站设置里有首页「加入 QQ 群」用的链接，就是这个群。

## 本轮范围

1. 报名的人在活动页报名区（登录后替换的那块）看到「分队结果发到社团 QQ 群，还没进群的点这里加入」
2. 开始前的提醒邮件加一行「社团 QQ 群」链接
3. 没填链接时两处都不出现
4. 设计 9.2（v6.33）；README

## 不做

- 活动页的静态部分（「管理员用系统自动分队，结果发到群里」）不加链接：改了群链接就得重新生成全部内战页

## 验证

测试：报名的人看得到链接，没报名的、未登录的看不到；没填链接不出现；提醒邮件里有、清空后没有。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
