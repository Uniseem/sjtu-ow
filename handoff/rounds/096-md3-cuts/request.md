# 096 不泛黄；不画边，用色块切开、圆角（分支 claude/flat-muted-ui）

## 背景

用户看了 095 的截图，又发来首页「公告」一块的截图（白色列表外一圈描边、行之间一条线、日期块），说：

> 有问题，首先，我不希望整体泛黄，这一点请保持原样。然后呢，类似图片的这种边缘，我不喜欢，改成类似 MD3 设计风格的那种纯色切割，不特地去勾勒出边缘的。然后可以做圆角处理

还在分支 `claude/flat-muted-ui` 上做，不合并。

## 本轮范围

**做**：

1. 浅色模式的中性色（底、卡片、表头、分隔线色、控件边框、三级文字、提示条）回到 v5 的值；强调色（砖红、沙杏等）和深色模式的深蓝灰不动（用户只说了「泛黄」）。错误页、样张页色板、邮件、设计表同步
2. 去掉所有用分隔线颜色画的描边和分隔线（33 处），靠白色卡片和灰色页面底的色差分开；输入框、复选框的边框保留（控件边界 3:1），文章 `<hr>` 和样张页白色色块的描边保留
3. 列表改成 Material 3 的分组列表：每行一块白色，行间露出 3px 页面底色，整组外角 16px、内角 4px；表格行之间是 2px 页面底色的切口
4. 圆角：新增 12px、16px 两档，卡片、面板、表格、菜单、提示、图片卡用 16px；按钮改胶囊
5. 卡片悬停从「描边变深」改成「底色深一档」；其余位置的小标签描边改成浅色块

**不做**：字体、布局；深色模式的颜色；强调色。

## 验证

测试：浅色中性色不偏暖（蓝 ≥ 红）；样式表里用分隔线色画边的只剩两处允许的；列表是分组的块；表格行是切口；登录卡没有描边、16px 圆角。变异逐条改坏。截图发给用户。

## 验收标准

`AGENTS.md`「常用命令」那组全绿；变异全部被抓到；提交在分支上并推送，不合并。
