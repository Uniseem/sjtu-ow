# 157 「我的报名」可以订阅到手机日历

## 背景

继续自主推进。以报了好几项活动的成员身份：156 让首页能看到「我接下来要打什么」，但要记得打开网站才看得到。大家平时看的是手机日历，社团的内战时间要自己抄进去，时间改了（139 会发邮件）还得再改一次。日历订阅（`.ics`）是所有手机日历都支持的标准做法，不用加依赖。

## 本轮范围

1. `core/calendar_feed.py`：内容和「我的安排」一样（`core.agenda.items_for`，不限条数），没有开赛时间的赛事不放；每项一个日程，「内战：标题」「赛事：标题」，内战预计 3 小时、赛事 4 小时，说明里写分队或队名和状态、活动页地址；文本按 RFC 5545 转义
2. 地址 `/calendar/<签名>.ics`：签名里只有用户编号（和退订链接一样不用登录，手机日历带不了登录态）；签名不对或账号停用返回 404；按访客 IP 每分钟 30 次；`Cache-Control: private, max-age=900`，`X-Robots-Tag: noindex`
3. 「我的报名」页最后加「订阅到手机日历」：`webcal://` 按钮、可复制的 `https://` 地址、别外传的提醒
4. 设计 13.5（v6.49）、README「报名」

## 验证

测试：内战变成日程（开始、结束、标题、分队写进说明），没时间的赛事不放；签名改坏、账号停用都 404；转义；页面给出两种地址；第 31 次请求 429。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级，用真实地址取一次日历。
