# 174 复核结果（自查）

## 结论

自查通过。超级管理员在用户列表里勾几个人点「删除」，原来会真的把人删掉；现在没有这个按钮了，停用也只能在编辑页填原因做。

## 判断里最没把握的

1. **改的是 Wagtail 的内部方法**：见报告。替代办法是 `before_bulk_action` 钩子拦下提交，但按钮还在、点了要到确认页才被拦；现在的做法按钮都看不到，测试守着
2. **批量停用一起关了**：要一次停用很多人的情况很少；真需要时逐个在编辑页停用，原因和取消申请都会照做
