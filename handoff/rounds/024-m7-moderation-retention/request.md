# 024 AI 审核记录的保留期

023 的核查里唯一一条「部分符合」：设计 15.5 要求 AI 审核记录「**已处理的保留 180 天，未处理的一直保留**」。现在清理任务根本不碰审核记录，所以后半截成立，前半截没实现。

023 当时把它列成「需要确认『已处理』指哪个字段」。**看了模型之后这个问题不需要问**：

```python
class Status(models.TextChoices):
    PENDING = "pending", "待复核"     # ← 没人看过
    OK      = "ok",      "无问题"     # ← 人看过了，判无问题
    HANDLED = "handled", "已处置"     # ← 人看过了，处置了
    IGNORED = "ignored", "忽略"       # ← 人看过了，决定忽略
```

「已处理」= 状态不是 `pending`。另有 `reviewed_at`（复核时间）可以作为 180 天的起算点。

## 任务

### T1 接进 `cleanup_old_data`

- 删除：状态不是 `pending`，**并且**处理时间在 180 天前
- 起算点用 `reviewed_at`；为空时退回 `created_at`（数据迁移或早期记录可能没有 `reviewed_at`）
- **`pending` 的一条都不能删，不管多久以前**

### T2 保留期可配置

设计附录里「AI 审核记录保留」一行标了「配置」，和 API 日志、Webhook 记录一样做成常量。

## 测试要求

至少覆盖：200 天前已处置的删掉、200 天前仍待复核的留着、100 天前已处置的留着、`reviewed_at` 为空时按 `created_at` 算、四种状态各测一次、`--dry-run` 不删。

## 验收标准

1. `ruff` / `pytest` / `makemigrations --check` / 生产 `check --deploy` 全部干净
2. 造出四种状态、不同时间的记录，跑一次清理，贴出删除计数和剩下的记录
3. 回归
4. 清理验证数据并查全库计数
5. git 提交，信息以 `024:` 开头
