# 185 页头账号菜单里加「管理后台」

## 背景

用户 184 后第一次以超级管理员登录前台，账号菜单里只有「个人中心、我的报名、我的战队、退出」：「超级管理员不是要配后台以及各种东西的吗？为什么还会有个人设置界面？反而是应该有的东西都没有」。

全站没有一处链到后台，能进后台的人（超级管理员、内容编辑、赛事管理员、内战管理员、认证作者、投稿者）只能自己在地址栏敲 `/admin/`。站长要配的发信、协议、上线清单都在后台首页。

个人中心照留：超级管理员在前台也是一个成员（昵称、头像会出现在文章署名和评论里），这些在个人中心改。

## 本轮范围

1. 页头账号菜单：能进后台（`wagtailadmin.access_admin`）而且不只是投稿者的人（`content.permissions.is_submitter_only` 为假：超级管理员、内容编辑、赛事管理员、内战管理员、认证作者）最上面一项「管理后台」，链到后台首页。验证过邮箱的成员都会被自动放进投稿者组、也能进后台写稿，只按「能进后台」判断的话人人都有这一项（第一版测试就这样红了）；他们用页脚的「我要投稿」
2. 页脚「账号」一栏同样
3. 设计 13.2.6、13.3、13.13.3（v6.64）

这两块都是登录后按人替换的区块（13.13.3），不进静态页。

## 验证

测试：超级管理员、内容编辑（后台角色）看得到，普通成员（投稿者）和访客看不到；从静态页加载区块的那条路（`state_fragment`）也一样。变异逐条改坏。

## 验收标准

整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；正式站升级。
