# 178 战队主页和管理页标出账号已停用的成员

## 背景

继续自主推进。177 让站长知道哪些队的队长被停用了；从队员和访客这边看：战队主页把被停用的成员和别人一样列出来，被停用的队长照样挂着「队长」标签、队头写「队长 X」，只是名字不再链到个人主页。队员找队长审批、报名，找不到人也不知道为什么；设计 3.7 说停用的账号不再出现在成员展示里，战队页却照常显示他的宣言和段位。队长在管理页上也看不出哪个队员被停用了、白占着名额。

## 本轮范围

1. 战队主页：被停用的成员照样列出（还占着名额），标「账号已停用」，不显示宣言和位置段位；队长停用了，队头「队长 X（账号已停用）」
2. 队长管理页：成员表里标「账号已停用」，提示可以移出、空出名额
3. 队长停用了的战队暂时不能申请加入（`can_apply` 多一条），提示「这支战队的队长账号已停用，等管理员指定新队长后再申请」：原来申请会发给一个登录不了的队长，等 14 天自动关闭
4. 设计 3.7、细节 5.3、5.5（v6.61）

停用时战队页会跟着重新生成：`is_active` 在触发重新生成的公开字段里（13.13.4）。

## 验证

测试：停用一个队员和队长后战队主页的标签、宣言不再出现、队头的说明；在用的成员不受影响；管理页的标签和提示。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
