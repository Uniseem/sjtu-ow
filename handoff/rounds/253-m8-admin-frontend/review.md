# 253 自查与独立复核

## 自查清单

1. **后台独立骨架与设计依据**：
   - 严格遵循 `docs/admin.md` 第 1-5 章；
   - 顶栏使用 `b-top`，包含品牌标志、8 个大类导航链接、当前项 `aria-current="page"` 高亮下划线，右侧包含打开网站、主题切换、用户昵称与退出链接；
   - 页头使用 `b-head`，支持大类 Kicker、页面标题、右上角主要操作按钮组、一级标签 `b-tabs` 与二级小标签 `b-subtabs`；
   - 内容区采用 `b-main`，编辑页采用 `b-split` 双栏排版（主表单 + 右侧 22rem 状态栏）；
   - 前台页面与后台页面在 `App.vue` 处通过路由前缀无缝分流，前台保留页头页脚，后台独享完整管理骨架，杜绝嵌套冲突。

2. **能力与权限拦截**：
   - 未登录访问 `/admin/*` 提示登录并引导至 `/accounts/login/?next=...`；
   - 非管理员用户访问 `/admin/*` 提示 403 并在前端阻断；
   - 八个大类与各个标签通过 `ADMIN_SECTIONS` 与 `isTabVisible` 严格按当前用户的 `superuser` 与 `caps` 过滤展示；
   - 后端已在 252 轮给所有 `/api/admin/*` 路由配备了严格的权限中间件（`api.Cap(...)`、`api.Superuser`、`api.Member`），即便绕过前端直接调用接口也会被 Go 服务端 403 拦住。

3. **代码分割与体积控制**：
   - 所有后台页面在 `web/apps/site/src/routes.ts` 中均通过 `() => import(...)` 懒加载路由分块；
   - 普通访客访问网站前台首页时，不会下载任何后台组件 chunk；
   - 实测构建产物首页壳 gzip 大小（HTML 2511 + CSS 19196 + JS 57886 = 79593 字节），严格符合 BUDGET-OK（上限 307200 字节）。

4. **前后端接口对齐**：
   - `GET /api/session` 注入 `superuser` 与 `caps` 列表；
   - `sjtuow apigen` 更新客户端类型；
   - 待办、全站设置、图片媒体库、头像审核、评论管理、赛事、内战、战队、分组、审计日志等全部与 252 轮 API 规范对齐。
