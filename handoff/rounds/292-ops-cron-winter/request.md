# 292 正式站 cron 冬令时修正

## 背景

用户本轮要求「按收尾文档开始做，先改 cron，再把剩下的代码全部写完后集中测试」。沿用 291 授权，执行 docs/final-batch.md 第 2 节，基线 03c050e。

## 本轮范围

只修改正式站 /etc/cron.d/sjtu-ow，并按规格备份到 /root/sjtu-ow-backups。记录文档与 STATUS；不部署、升级、重启、清理磁盘或修改数据库、环境变量及服务器代码。

## 任务与验收

1. 只读探查时区、现有 cron、at-shanghai.sh 和旧站 Compose 服务。
2. 确认脚本与本地一致后，备份并将全部条目改为每小时触发、北京时间判定。保留现有 moderate_scan --digest 额外条目（北京 09:30）；备份参数按批次模板显式永久保留。
3. 核对内容、属主权限及末尾换行；验证当前/其他小时及冬令时前后北京 03:00。
4. 记录整点 cron 触发和次日备份、预渲染证据。未到时间的自然运行验收写待验证，不伪造。
5. 测试机后台整组通过后，一个中文提交推 main，核对该 SHA CI。
