# 238 M2 第八轮：样张页和旧站并排截图

## 背景

M2 的完成标准是样张页和旧站并排看起来一样，首页壳 gzip 不超过 300 KB。体积已经进检查。`/static/img/` 也接上了。这一轮把两边的 `/_styleguide/` 在同一台机器、同一个浏览器里截下来比。

字体库（D4）在 M8。比较时两边都不挂后台生成的排版样式表，只用设计体系那份样式。

## 本轮范围

### 做

1. 新站样张包在 `<main id="main">` 里，和现行站的正文位置一样。
2. 测试机上同时起现行站和新站，用无头 Chromium 在 1280 宽、浅色、减少动态效果下截 `#main`。正文文字要一致。像素差超过 0.8% 或高度差超过 4px 算没通过。图留在 `/tmp/sjtu-ow-stylecompare/out/`。

### 不做

- 字体库、头像图片（账号区的默认头像是 M3）。正式站。
- 把这次截图放进每次 `pnpm test`（要起 Django，太重）。

## 验收标准

测试机上整组通过，比较脚本退出码 0。一处变异：拿掉 `id="main"`，样张测试变红。
