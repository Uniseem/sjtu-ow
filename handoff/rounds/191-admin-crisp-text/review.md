# 191 复核结果（自查）

## 结论

改了最可能的两个原因（非整数字号、苹方在 Windows 上），文字也加深了一档。没法在用户的屏幕上确认，等用户反馈；如果还糊，要一张截图和浏览器、系统缩放比例来查。

## 判断里最没把握的

1. 189 之前后台也是 13.6px，用户当时没说糊；189 改了字体栈和颜色以后才说。字体栈在这台机器上解析出来仍是微软雅黑，所以「189 以后才糊」的真正原因可能不止字号
2. Wagtail 里还有少数按比例算的字号（`.9em` 之类），14px 下仍是小数
