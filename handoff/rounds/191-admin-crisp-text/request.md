# 191 后台文字发虚

## 背景

189 换了后台外观后，用户 10-04：「后台看的和散光一样」，问是哪种感觉时答「不是啊，你那个字体可以做成模糊的了」——文字本身是糊的。

查下来：Wagtail 把后台正文设成 `font-size: 85%`，也就是 13.6px；微软雅黑这类中文字体在 Windows 上用非整数的小字号会发糊，前台正文是整数的 16px。另外后台的字体栈照前台抄，苹方排在微软雅黑前面：自己装过苹方的 Windows 电脑会优先用苹方，苹方在 Windows 上小字号同样糊（开发者这台没装苹方，只有微软雅黑）。189 还把次要文字和侧栏文字用了较浅的 `fg-3`、`fg-2`。

## 本轮范围

1. 后台正文 14px（整数）
2. 后台字体栈微软雅黑排到苹方前面（Mac 没有雅黑，照样用苹方）
3. 次要文字从 `fg-3` 加深到 `fg-2`，侧栏菜单文字从 `fg-2` 加深到 `fg`
4. 设计 14.1 外观那一条补上

## 验收标准

测试：样式里正文是 14px、雅黑在苹方前、两处颜色；变异逐条改坏。用户在自己电脑上看不再发虚。
