# 283 评论类型接入与真实Go旅程

## 背景

用户授权规划后自主推进，282补公开门。现在接BE-4/7/8并验证真正的评论写操作，避免把桩API浏览器当成真实旅程。

## 本轮范围

- 本轮前后端范围例外：apigen生成递归结构体引用，保留nullable/omitempty/JSON字段；只通过apigen更新gen。
- ArticleDetail和评论UI直接接生成类型，移除BE-4/7/8临时扩展/unknown递归转换；edited_at独立显示，隐藏/置顶不伪造已编辑，null节点正确跳过。
- 真实评论规则核查发现编辑接口漏每日限额声明，本轮按旧R177补齐并验证；不更改设计数值。
- 测试机临时Go API+生产SSR+真Caddy+Chromium旅程：访客只读，成员发表/回复/编辑/点赞/取消/删除，管理隐藏/恢复/置顶/取消，分页/排序、真实限流失败保留草稿、禁用权限/关闭评论提示与公开门404。每步检查真实接口和数据库状态、浏览器异常/CSP。
- 不改旧站、不加第三方依赖、不部署；账号全旅程和F5–F10继续后续轮次。

## 验收标准

1. 递归结构单链/互相引用保留时间与nullable，不再unknown；生成顺序稳定，标识符唯一。先用Go生成器回归与可编译变异证明。
2. SSR/组件验证edited_at（顶层/回复）与更新动作区分、null节点不报错、ban不提供发表，编辑请求拒绝并保留草稿；自身编辑/删除按钮照旧模板，评论UI日期/文案照旧。
3. 真实Go浏览器逐步断言、原桩浏览器回归、整组与文章四组合对拍；失败真实记录，未跑写未验证；request/report/review/STATUS，一个中文提交、推main看对应CI。
