# 032 内战分队改成拖拽

用户定的：

> 内战调整可以做成拖拽的，但是给一片缓冲区，要换人时得先把满员的队伍拖一个人出去放缓冲区。

021 轮我做成了下拉选择，并在报告里说明「这是我主动的取舍，不是做不到」。现在按用户说的改。

## 任务

### T1 三区拖拽

A 队、B 队、缓冲区。角色限定规格下每队按位置分三个小区（坦克/输出/支援），**拖进哪个位置区就是分到哪个位置**——不用再单独选位置。

### T2 满员规则

**队伍满员时拒绝拖入**。要换人先把人拖到缓冲区腾位置。

拒绝比「先放进去再标红」好：屏幕上看到的永远是一个能直接保存的状态。

### T3 不只能用鼠标

每张卡片上带 A / B / 缓冲 三个按钮，键盘和触屏也能移动，走同一套规则。

### T4 保持原有的保存契约

拖拽只更新隐藏字段，POST 的字段名不变，后端不用改。

### T5 位置人数不符仍可保存

设计 9.5 要求「标红提示，但仍然允许保存」——位置区的数量不符只标红，不拦。**只有队伍总人数是硬规则**（用户的要求）。

## 测试要求

角色限定有三个位置区、不限位置没有位置区、缓冲区存在、满员规则依赖的属性都在、缓冲区里的人保存后还在、POST 字段名没变、没有 Alpine 属性、Sortable 来自本站。

拖拽本身的行为在真实浏览器里验，贴输出。

## 验收标准

1. `ruff` / `pytest` / `makemigrations --check` / 生产 `check --deploy` 干净
2. 真实浏览器里走一遍：满员拒绝 → 拖到缓冲区 → 换人成功 → 保存
3. 控制台无错误
4. 清理验证数据
5. git 提交，信息以 `032:` 开头
