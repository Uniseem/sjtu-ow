# 075 首页与内容页

## 背景

074 定了设计体系（设计 v2.0 13.2 节）和外框，页面内部还是旧模板。本轮改「刊物」这一侧加首页：首页、资讯列表、文章页、普通页面（协议、隐私、关于）、评论区、搜索结果、投稿入口。

## 本轮范围

**做**：

1. 首页按设计 5.2 的五个区块重做：头条（焦点图 `c-feature` + 近期票根）、01 资讯、02 赛事与内战（深色，日程带 + 票根 + 内战列表）、03 战队（图块墙）、04 参与
2. `content/home.py` 的数据跟着改：删掉图片新闻和月历，新增「近期」（正在报名的赛事和 7 天内的内战，按日期合并，最多 4 条）、14 天日程带（公开和已结束的内战、开赛的赛事）、赛场区块的赛事（报名中在前、即将开放在后，最多 3 个）、成员总数；要闻改为 6 篇
3. 焦点图脚本 `static/js/carousel.js` 按新标记重写：编号索引、进度红线、悬停 / 聚焦 / 切到后台 / 减少动态效果时停
4. 资讯列表：栏目头、分类标签条（`c-tabs`，当前项红线）、列表行（日期、分类、标题、摘要、有封面带缩略图）、侧栏投稿入口、分页
5. 文章页：面包屑、分类、标题、日期和作者、封面、正文（`c-prose`）、文末作者和栏目、关联赛事的票根、评论区；桌面右侧「同栏目最新」4 篇
6. 正文块模板（图片、引用、视频）按 `c-prose`
7. 普通页面：刊物正文 + 左侧「关于本站」
8. 评论区（5.6 节）：方形首字头像、回复串、点赞 / 回复 / 编辑 / 删除 / 置顶 / 隐藏按钮换成新组件；所有 HTMX 行为不变
9. 搜索结果：大搜索框、按类型分组的列表行、每组数量
10. 投稿入口的「不能投稿」页
11. 样张页补上焦点图和评论

**不做**：赛事、内战、战队、成员（076）；个人中心、登录注册、表单（077）；评论、搜索的业务逻辑。

## 验收标准

- 整组检查全绿
- 新规则都有测试并做变异：近期的合并排序和上限；日程带的范围（14 天、只数公开和已结束的内战、只数开赛的赛事、标今天）；赛场赛事的顺序；文章页用 `c-prose`、显示封面、同栏目最新不含本篇和别的栏目；资讯分类标签标当前项；首页没有焦点图时不加载脚本
- 桌面 1280 和手机 390 截图：首页、资讯、文章（未登录和登录）、协议页、搜索
