# 133 全站设置加「测试对象存储」

## 背景

继续用户 2026-10-04 睡前的要求（假定各种身份走流程）。以第一次部署的站长身份：122 轮的上线清单提示「异地备份没开」，站长照着在全站设置里填了对象存储地址、存储桶、Access Key。填对没有？SMTP 有「发送测试邮件」、AI 有「试一下」（122），对象存储什么也没有，只能打开上传、等到夜里 3 点备份跑完看日志，错了再等一天。

## 本轮范围

1. `core.offsite.probe()`：用已保存的设置往前缀下写一个小文件再删掉；缺设置、连不上、写失败、删失败分别说清楚；不要求先打开上传；没设 `BACKUP_ENCRYPTION_KEY` 时提醒
2. 全站设置页「发送测试邮件」下面加「测试对象存储」按钮，只有能改全站设置的人能用
3. 上线清单的异地备份一项提到这个按钮
4. 设计 16.7、后台表（v6.28）；README

## 验证

测试：写入后删除、文件名在前缀下；没开上传、没设密钥时的提示；缺设置、写失败、删失败各自的说法；设置页有按钮、站长点了成功、内容编辑点了被拦且存储桶没被碰。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
