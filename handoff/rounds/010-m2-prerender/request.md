## 任务

### T1 数据表（设计 12.4.6）

`PrerenderedPage`：`path` 唯一、`kind`、`status`、`requested_at`、`generated_at`、`content_hash`、`bytes`、`error`。

### T2 生成器（设计 13.13.4、13.13.5）

1. 用线上同一套视图和模板，**以未登录访客身份**渲染：不带 Cookie、不带会话、不带操作提示。
2. 写 `<预渲染目录>/<路径>/index.html`，同时写 `.br` 和 `.gz`；**先写临时文件再原子重命名**。
3. 内容哈希没变就不重写文件（`content_hash` 字段）。
4. **安全闸门**：响应带 `Set-Cookie`、正文里出现 CSRF token 或会话标记时，拒绝写文件并记 `error`。
5. 删除单页；删除失败要记录错误。

### T3 任务与合并（设计 13.13.4）

1. `prerender_page(path)`：同一页面 30 秒内的多次请求只执行一次（**默认**）。
2. `prerender_all()`：全量重新生成，供每日兜底和升级后使用。
3. `remove_prerendered(path)`：立即删除静态文件。
4. 兜底：访客请求到还没有静态文件的公开页面时，Django 正常渲染，同时排一个生成任务。

### T4 触发事件（设计 13.13.4，只做 M2 部分）

| 事件 | 处理 |
|---|---|
| 文章 / 普通页面发布、修改 | 重新生成该页，以及文章列表和首页 |
| 撤回发布、删除 | **立即删除**该页静态文件，重新生成列表和首页 |
| 网址片段修改、移动 | **立即删除旧网址**的文件，生成新网址的页面 |
| 排版设置保存（字体样式表变化） | 全量重新生成 |
| 文章分类修改 | 列表页 |

### T5 页面状态片段（设计 13.13.3）

1. `GET /_fragments/state/?slots=account,messages`，一次返回全部占位区域，HTMX 带外交换填进去。
2. 响应头 `Cache-Control: private, no-store`，随 Cookie 变化。
3. 会话已失效时返回未登录内容，并删除 `ow_logged_in` 提示 Cookie。
4. 保证 `csrftoken` Cookie 已设置（预渲染页面里没有 token）。
5. 限流：每个 IP 每分钟 120 次（附录 C）。

### T6 提示 Cookie 脚本（设计 13.13.3）

1. `<head>` 里同步加载的小脚本（**压缩后 1KB 以内**），只读 `ow_logged_in` / `ow_flash` 两个 Cookie。
2. 两个都没有 → 什么都不做，**未登录访客不发任何额外请求**。
3. 有 → 先加「已登录」样式和骨架，再由 HTMX 发一次 `/_fragments/state/` 请求，占位区域列表从页面上的 `data-slot` 自动收集。
4. 脚本失败时页面保持未登录内容，链接仍然指向实时渲染页面。

### T7 后台「设置 → 静态页面」（设计 13.13.6）

超级管理员可以：查看已生成页面数、最近生成时间、失败页面和原因；重新生成单页 / 全部；清空全部静态文件（清空后自动回落实时渲染）。

### T8 命令与运维

1. `manage.py prerender`（全部 / 单页 / 清空），供每日 cron 和升级后使用。
2. README 补：开关、目录、cron 示例、从备份恢复后要清空预渲染目录。
3. 设计 13.12.2 补一句「被替换的字体分片延迟一天删除」（009 遗留的文档项）。

## 测试要求

至少覆盖：生成的文件落在正确路径且带 `.br` / `.gz`；内容没变时不重写；撤回发布立即删文件；改 slug 删旧文件生成新文件；30 秒合并；未登录访客的页面里**不含** CSRF token、邮箱、会话 ID（扫描全部生成文件）；片段接口未登录 / 已登录两种返回、响应头、删除提示 Cookie、限流；`PRERENDER_ENABLED=False` 时全部逻辑安全跳过。

1. `ruff` / `pytest` / `makemigrations --check` / 生产 `check --deploy`

5. 改一篇文章的 slug，贴出旧文件被删、新文件生成

7. 回归：前台各页、`/me/`、`/healthz`、后台
8. `docker build`、`caddy validate`
9. git 提交，信息以 `010:` 开头
