# 087 刊物页按 v4.0 重做：资讯、文章、普通页面、搜索

## 背景

M10 第二轮。086 定了 v4.0 的体系和首页，其余页面靠 v3 令牌别名换了颜色，版式还是 v3 的。这一轮做设计 13.2.7 的「刊物列表」和「刊物正文」两种骨架。

## 本轮范围

**做**：

1. 资讯列表：栏目头（「我要投稿」改描边按钮）、`c-tabs` 改成下划线式筛选、`c-media` 图片卡网格（桌面三列），分页改 v4 样式；没有封面的卡片是灰底写分类名，`category_wash.html` 删除
2. 文章页：`c-article` 44rem 正文栏居中（v3.1 作废时一起撤回的「文章页居中」在这里做）；作者行；头图；正文；关联赛事改成 `c-feature` 小卡；评论区；正文后面一行同栏目最新 3 篇图片卡
3. 普通页面（关于、协议、隐私）：同一正文栏，标题上方一行 `c-tabs` 切换三页，`about_side.html` 删除
4. 搜索：`c-searchbar` 改 v4；结果按类分组成 `c-rows --plain`；去掉搜索栏下的说明小字
5. 正文 `c-prose` 改 v4：引用左侧竖线、不填底色；图片 8px 圆角
6. 删掉 v3 的列表行（`c-rowlist`）、文章卡（`c-post`）、文末信息（`c-byline`）、同栏目最新（`c-related`）样式；账号安全页和样张页里用到列表行的地方跟着换成 `c-rows`
7. 投稿页换 v4 样式（没有新组件）

**不做**：评论区的版式（089）；赛场、名册（088）。

## 验证

- 资讯列表是 `c-media` 卡片、筛选当前项唯一；没封面时卡片写分类名
- 文章页栏居中（样式里 44rem、`margin-inline: auto`），同栏目最新在正文后面、不含本篇和别的栏目
- 关于 / 协议 / 隐私互相链接、当前页唯一
- 搜索结果分组、没有说明小字
- 引用不填底色
- 变异（先跑基线）；截图浅色、深色、375
