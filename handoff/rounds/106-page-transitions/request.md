# 106 页面切换：加载过渡，不闪、不弹入

## 背景

用户 2026-10-03：

> 其次，切换时我希望是有过渡动画的，减少不流畅感

现在点链接是浏览器的硬切换。设计 13.2.4 原来写着「不做进场动画」。第一版做的是「旧页 120ms 淡出、新页 240ms 淡入并上移 8px」，用户在本机看了以后：

> 你是不是没做懒加载？而且现在整个页面切换时闪烁有点严重。其次，我要的是过渡的加载动画，不是最终的弹入动画！

两个问题都对：旧页淡出到透明、新页再从透明淡入，中间整页透出底色，就是闪；动画放在新页面已经到了以后，用户要的是**等待时**有东西在动。懒加载另开 107。

## 本轮范围

**做**（先改设计 13.2.4、13.2.7，记 v6.4）：

1. **等待时的加载条**：点了站内链接（或提交会离开本页的表单）150ms 后，页头底边出现一条 3px 的强调色加载条，先快后慢地往前走，自己不会走完；新页面到了随旧页淡掉。已经提前准备好的页面（105）点下去就到，不出现。下载、新窗口、站外、本页锚点、HTMX 局部刷新不出现；15 秒还没离开自己收起；从后退缓存回来时收起。`static/js/loading.js`
2. **换页那一下不闪、不弹入**：浏览器自带的跨页面过渡，只把默认的交叉淡化缩短到 150ms，用浏览器默认的混合方式（亮度不掉）；不做上移、弹入。页头单独成一层不动
3. **切换深浅色**：整页 240ms 交叉淡化
4. **页内锚点**平滑滚动
5. 系统设了「减少动态效果」时：没有交叉淡化和平滑滚动，深浅色直接切；加载条照样出现但不动
6. 两个导出个人信息的链接加 `download`，加载条和提前准备都跳过它们

**不做**：评论区局部刷新的动画；图片（107）。

## 验证

测试：样式、页面结构、`loading.js` 和 `theme.js` 里的每条规则；变异逐条改坏。无头 Edge：换页时实际跑的过渡动画（名字、时长）、深浅色切换走过渡、加载条在点击后 100ms 还没出现、之后逐渐变宽，截图。
