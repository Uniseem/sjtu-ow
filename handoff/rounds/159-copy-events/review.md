# 159 复核结果（自查）

## 结论

自查通过。每周的内战、每年的赛事不用再从空白表单填起：上一场「更多 → 复制」，改一下要改的就能保存，时间已经挪到下一周或今年。

## 判断里最没把握的

1. **按整周挪**：内战基本是每周固定时间，整周挪最省事；赛事一年一次，挪 52 或 53 周落到同一个星期几，日期差一两天，管理员本来就要核对。隔周、每月的活动挪完还要再改
2. **至少挪一周**：在一场还没开始时复制（提前排下周的），落到它的下一周，而不是和它重叠
3. **标题照抄**：赛事标题里常带年份（「2026 新生杯」），要管理员自己改；自动改年份容易改错别的数字，没做
4. **只抄列出的字段**（`COPIED_FIELDS`）：比「抄全部、排除几个」安全，代价是以后表单加字段时要记得在这里决定；有测试会提醒

## 写测试时发现的

第一版照 Wagtail 自带的复制页，拿原来那条记录预填表单，只把时间改了、主键清掉。页面上的表单提交到新建地址，看起来没问题；但测试把表单直接提交回复制地址时，新建出来的那条带着原来的状态（「已发布」「已结束」）、发布时间这些不在表单里的字段：等于不经过发布流程就多了一场已发布的内战。改成只照抄列出的字段、新建一个对象。
