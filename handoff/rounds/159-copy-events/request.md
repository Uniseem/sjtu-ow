# 159 内战、赛事可以「复制」成新的一场

## 背景

继续自主推进。以内战管理员的身份：演示站上「周日下午 · 新人友好场」这种每周都有的内战，每次都要在后台从空白表单新建：标题、说明、规格、仅限交大、两个时间全部重填。赛事管理员每年办一次新生杯也一样。Wagtail 自带「复制」，但 014、020 建后台时把它关了（`copy_view_enabled = False`），没写原因，估计是怕把状态、通知记录一起复制过去。

看过 Wagtail 的实现：复制页只是把原来那场的表单字段填进「新建」表单，提交到新建地址，建出来的是新的一条。状态、提醒、通知记录不是表单字段，不会被带过去；原来那场不会被改。

## 本轮范围

1. 内战、赛事列表的「更多」里出现「复制」，打开的是预先填好的新建表单
2. 带过去：标题、说明、封面、规格或报名规则、仅限交大、自动通过、选手联系方式这些表单字段
3. **时间按整周往后挪**，挪到最早的那个时间也在将来为止（每周的内战落到下周同一天同一时间，去年的新生杯落到今年同一个星期几）；至少挪一周。没填的时间（比如赛事没定比赛时间）保持空
4. 新建出来的是草稿，没人报名，没发过通知；创建人是点复制的人；保存走和新建一样的流程
5. 设计 14.2（v6.51）；后台手册里内战管理员、赛事管理员各加一句

## 验证

测试：复制页里的时间往后挪了整周、在将来，标题等字段带过去；提交后多一场草稿，原来那场没变；内战管理员能复制内战、不能打开赛事的复制页；列表里有「复制」。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
