# 183 演示站转正式站（保留图片库）

## 背景

用户 10-04：「现在这个站点，给他变成正式的吧。封面图片之类的保留啊，后面要沿用的」。

182 演练的转换是整库清空，图片库也会一起没。这次要的是：演示的人和内容（40 个 `demo.example.com` 账号、战队、文章、评论、赛事、内战、报名）清掉，**图片库原样保留**（默认封面的几百张、默认头像的英雄立绘、「头像」集合、根目录的封面占位图和队标），以后发文章、建赛事接着用。

## 做法

不在旧库里逐表删（Wagtail 的修订记录、日志、审核记录、任务记录都挂着演示账号，删不干净），而是换一个干净的库，再把图片库搬回去：

1. 先留底：`.env` 拷一份、最后一份完整备份拷出备份卷、旧库连同 WAL 改名留在数据卷里
2. 导出图片库（`export_images.py`）：每张图的标题、文件路径、说明（动漫头像的画师和出处记在这里）、尺寸、焦点、大小、哈希、上传时间、所在集合；上传人不留（是演示账号）
3. 停 web、worker；旧库改名；删掉缩略图（`media/images`，会按需重新生成）、字体目录（`init_site` 会重建）、静态页；**原图 `media/original_images` 不动**
4. 新库：`migrate`、`createcachetable`、`init_site`
5. 导回图片库（`import_images.py`）：按名字重建集合树，图片行指向原来的文件
6. 去掉 `TEST_ENVIRONMENT`，重建容器，全量生成静态页

不带过去的：全站设置里的成立日期 2019-09-15 是造演示数据时写的（`seed_demo.py`），假的；其余设置都还是默认值。

本机先用开发库的副本演练了导出、导入：478 张、64 个集合，导回后再导出，两份逐字段一致。

## 验收标准

正式站上：用户、战队、文章、评论、赛事、内战都是 0；图片 478 张、集合和原来一样，后台图片库能看到缩略图；首页等页面 200，没有测试环境横幅，`robots.txt` 不再禁止收录；`/healthz` 200；演示站的最终备份和旧库都留着，能回去。README「演示站转正式站」改成保留图片库的做法。
