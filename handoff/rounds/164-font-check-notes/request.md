# 164 服务器上验证字体处理，记下 159、163 踩到的坑

## 背景

继续自主推进。翻 `handoff/REVIEW-GUIDE.md` 找还没了结的地方：064 那段写着「worker 做的事（邮件、字体处理、预渲染）在服务器上各真跑过一次没有……字体处理还没在服务器上跑过」。预渲染 064、158 在服务器上验证过，邮件要等你配 SMTP，字体处理一直没跑过。064 的教训正是「在 web 里跑通不等于 worker 能跑」。

159、163 里踩到几处以后还会遇到的坑，`AGENTS.md` 的「已知的坑」还没写。
