# 028 附录 A 段位编码核查

026 查了附录 C 的数字，027 查了附录 B 的枚举，这轮查附录 A 的段位编码。

**这 41 个数字是内战分队算法唯一的输入。** 编码错一格，分出来的队看起来完全正常，但实际是歪的——不会报错，不会有人发现。

## 任务

按附录 A 的公式 `分数 = 大段序号 × 5 + (5 − 小段)` 逐格验算 8 个大段 × 5 个小段 + 前 500 + 未定级，编码和解码都要对，写成测试。

## 验收标准

1. `ruff` / `pytest` / `makemigrations --check` / 生产 `check --deploy` 干净
2. 贴出全表验算结果
3. 变异测试确认测试咬得住
4. git 提交，信息以 `028:` 开头
