# 040 补上预渲染安全闸的测试

039 轮的变异测试找到 3 个空白，这是其中最严重的一个。

`core/prerender.py` 有三道安全闸（设计 13.13.4）：状态码/类型不对、响应带 Set-Cookie、正文命中 `SECRET_MARKERS`。**把 Set-Cookie 那道拆掉，全量回归一条都不红。**

它防的是：一个会给访客设 cookie 的页面（说明是个性化的）被冻成静态文件，然后**所有人看到同一份**——包括别人的 session。
