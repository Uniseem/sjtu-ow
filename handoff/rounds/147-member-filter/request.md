# 147 成员展示按常用位置筛、只看还没进战队的

## 背景

继续自主推进。140 让找队的人能按缺的位置找战队；反过来，以想招人的队长身份：我缺一个支援，想在成员展示里找「常用位置是支援、还没进战队」的人。成员展示只有分组和「全部成员」，没有任何筛选，几十个人要一张张看。常用位置、所在战队本来就公开显示在卡片上。

## 本轮范围

1. 「全部成员」上方加筛选：全部位置 / 坦克 / 输出 / 支援，再加「只看还没进战队的」（可以和位置一起用）
2. 带参数的链接，实时渲染；筛选时只列筛出的人，编号保持全站的加入顺序，分组区块不显示；筛不到时说「没有符合条件的成员」
3. 不认识的位置参数当作没筛
4. 设计 6.3（v6.40）；README
5. 顺带：146 的截图工具加深色模式参数（`screens.py 375 dark`）和成员筛选页

## 验证

测试：按支援筛出两个辅助、编号是 002/003、不显示分组；加「只看还没进战队的」只剩没队的；只勾没进战队时三人；不筛时四人且有分组、有筛选栏；筛输出时提示；不认识的参数列全部。变异逐条改坏。测试机截图看手机排版。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
