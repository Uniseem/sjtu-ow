# 268 F3 账号入口第一组

## 背景与范围
用户要求继续补完前端，并明确「多写代码少测试」，必要检查仅在测试机后台执行。按现行模板、设计 3.1/3.2/13.2 和 frontend-migration 6.1，实现登录、注册、邮箱验证码、退出、停用说明、重新认证、修改密码及废弃入口跳转。找回密码与改邮箱的后端流程缺口在下一组接着做。

## 实现
账号页用 AuthLayout/CField，字段与提示照 allauth 实际表单；请求使用生成的 API 客户端；校验错保留输入、显示首个字段错误；防重复提交；next 只认站内地址；verify_required 去输码，验证成功自动登录并带一次性欢迎提示；重发验证码冷却；GET 退出只确认，POST 才退出；旧地址 301/302 真跳转兼容 SSR 和客户端导航。
依 12 号 6.4 补齐会话一次性提示：Go 保存、普通 session 读取消费；写后 refresh 只更新身份，不能提前吃掉跳转提示。

## 必要验收
实现完成后在测试机后台一次整组与 browser-check；账号页面组对拍和必要的请求/跳转回归。等待期间继续写下一组，不循环重复整组或扩展全站巡检。没有跑过的验收不判完成。
