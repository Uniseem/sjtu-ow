# 091 设计 v5.0 / v5.1：两个强调色、栏目页头图、首屏校徽、深浅色切换、会动的占位图

## 背景

2026-10-02 用户在本机看 090 之后的站点，一路提了下面这些要求。这一轮是跟着用户的反馈一步步改出来的，中间几版被否掉（见下），所以本文件写的是**最后定下来的范围**，被否掉的几版只记结论。

1. 「背景太空了」，想要「类似 antigravity 官网那种会随鼠标变动的粒子效果」。试过手写的全站背景粒子、Vanta.js 的 GLOBE、硬币式徽章，最后做出 three.js 的全光点首屏（点阵波浪、光点球、正面交大校徽反面守望先锋图标的光点徽记），用户说「这一版可以」，同意把守望先锋圆形标志收进仓库（设计 v4.2）
2. 「整个网站的设计，都需要重新规划规划，主色一个是 sjtu 的深红色，副色用 ow 的橙色，能理解吗，所有部位都重新考虑怎么做」
3. 看了新的资讯页：「像这种界面，背后还是要图片的」
4. 「还不错，但是首页风格就对不上了。首页也改回静态图吧，然后交大的那个标志还是放在右半部分，齿轮缓慢旋转」。**光点场景、three.js、守望先锋标志全部撤掉**（设计 v5.0）
5. 「感觉网站很不正式啊，特别是首页，还有所有的 ui」「ui 的 ai 味太浓了，整体设计风格也不统一，字体字号千篇一律」。试了一版「印刷排版」（白纸黑字、直角、细线、字号拉开），用户说「不行，回归上一版」，**整版撤回到 v5.0**
6. 「交大的标志可以大一些，并且有一定的透明度，这样看起来是融合在背景里的」
7. （截图里箭头指着首屏下面的数字条）「这一栏可以放到首页去，记得风格要统一。然后首页现在也有问题，现在明显是暗色模式。全站需要区分亮色模式和暗色模式并且可自由切换（默认是跟随系统）。之后现在的这些图片，都变成动图」（设计 v5.1）

## 本轮范围

**做**（设计 v5.0 + v5.1，先改 `docs/design.md`）：

1. **两个强调色**：交大深红（主要按钮、链接、站点标志）+ 守望先锋橙（当前导航和筛选的下划线、「报名中」、进度条、首页数字）。新令牌 `accent`、`accent-text`、`accent-soft`、`on-accent-soft`；`warn` 改偏黄，和橙色分开
2. **栏目页头图**：资讯、赛事、内战、战队、成员五个栏目页头背后有图；全站设置新增五个「栏目横幅」字段，没上传用这个栏目固定的占位场景；改了横幅刷新对应栏目页
3. **首屏**：全屏；背后静态图（全站设置「首屏图片」，没上传用首页的占位场景）；左边两行标题；右边交大校徽，**放大、半透明**，齿轮那一圈 90 秒转一圈（校徽拆成两层，CSS mask 着色）
4. **数字条并进首屏底边**
5. **深浅色切换**：页头「颜色模式」（跟随系统 / 浅色 / 深色），默认跟随系统，选择存在 `localStorage`；`<head>` 里的 `theme.js` 在画页面前写 `<html data-theme>`；样式用自定义的 `dark` 变体。**除页脚和带封面的横幅外，所有部位跟着模式走**（v5.0 的页头、首屏、栏目页头、数字条在浅色下也是深色，这正是用户说的「明显是暗色模式」）。手机上开关在菜单里
6. **首屏和栏目页头的占位场景各有白天版**：同一个随机种子、白天的配色，浅色模式显示
7. **占位图都会动**：图里自带 CSS 动画，`<img>` 放出来就会动；「减少动态效果」时停；原来的构图不变
8. 文档：`docs/design.md`（v5.0、v5.1）、README、AGENTS.md、`THIRD_PARTY_NOTICES.md`（校徽两层）

**不做**：

- 光点场景、three.js、守望先锋标志、「首屏徽章背面图」字段：v5.0 撤掉，**不进仓库**（只在本地出现过，没有提交）
- 「印刷排版」那一版：用户否决，全部撤回
- 错误页（`error.css`）不加切换按钮，仍跟随系统
- 上传的封面不会变成动图（只有本站画的占位图会动）
- 不新增依赖

## 任务和验证

| 任务 | 验证 |
|---|---|
| 颜色令牌 | 测试：两种模式的对比度（新增 `accent-text` 4.5:1、`accent-display` 大字 3:1、`on-accent-soft`）；每个令牌都有深色值；`night-*` 等于深色模式的同名值；样张页色卡和令牌一致 |
| `dark` 变体 | 测试：样式表里 `prefers-color-scheme` 只出现在变体里；编译出的两条规则（跟随系统、手动选深色）都带深色值 |
| 切换按钮 | 测试：`theme.js` 在 `<head>`、在样式表前；页头和抽屉各一份菜单，三项，默认 `hidden`；脚本记住选择、选「跟随系统」时清掉、存储出错不崩 |
| 跟着模式走 | 测试：深色条只剩页脚和带封面的横幅；页头、栏目头、首屏、数字条、横幅的规则里没有 `night`；首屏和栏目页头的压层用 `bg`；渐变只出现在图上的压层 |
| 场景图 | 测试：首屏、五个栏目页头没上传图时两张（白天 / 夜里），上传了只有一张；样式只显示当前模式那张；白天版和夜里版的形状完全一样 |
| 动图 | 测试：每张图都有动画、每条动画规则都有元素在用、`<style>` 里只有类规则 / 关键帧 / 「减少动态效果」那一条；42 张文件和生成器逐字一致 |
| 首屏 | 测试：数字条在首屏底边；校徽透明度、颜色是令牌、齿轮 90 秒；校徽两层和拆分器一致、齿轮是最长那条路径；QQ 按钮两种模式都能看清 |
| 横幅刷新 | 测试：改五个栏目横幅各自刷新对应栏目页，不改不刷新 |
| 查询数 | 战队列表的查询数不因栏目横幅增加 |
| 变异 | 逐条把上面的规则改坏，对应测试要红 |
| 截图 | 无头 Edge：首页、资讯、赛事详情，浅色 / 深色 / 手机；页面里点切换 |
