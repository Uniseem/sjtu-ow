# 150 后台待办列出没发出去的邮件

## 背景

继续自主推进。以站长的身份：邮件全部走 worker 队列，失败后重试 3 次（1、5、30 分钟），最后一次也失败就放弃，只在任务表里留一条「失败」。SMTP 密码填错、邮件服务商拒收时，注册验证码、提醒、通知全都发不出去，网站上却没有任何地方提醒，健康检查也只看排队过久的任务。

## 本轮范围

1. `core.admin_todo.mail_failures()`：最近 7 天里最后一次重试（第 4 次尝试）也失败的发信任务数，和最近一封的错误（traceback 最后一行，120 字以内）
2. 后台首页待办给超级管理员加一行：「最近 7 天有 N 封邮件重试后仍没发出去（错误），检查全站设置里的 SMTP，先发一封测试邮件」，链到全站设置
3. 还会重试的中途失败、7 天以前的、成功的都不算
4. 设计 14.1（v6.43）

## 验证

测试：只算 7 天内最后一次也失败的一封，显示错误和全站设置链接；内容编辑看不到；只有中途失败时没有这一行。变异逐条改坏。演示站上实际看一次。

## 验收标准
