# 124 新成员上手

## 背景

用户（2026-10-04 睡前）要求假定各种身份把流程走一遍：「比如你是用户，你要注册，要加入战队，或者比赛，要展示自己，要发表文章，可以一路通畅吗？」

在本机空库上，以一个新成员走了一遍（`scratchpad/walk_member.py`：注册、读验证码、确认，再打开个人中心、战队、申请入队、赛事、个人报名、内战、成员展示、投稿）。整体能走通，卡顿的地方：

1. **验证完邮箱落到首页**，没有欢迎，也不提示先补游戏 ID 和联系方式（不补什么都报不了）
2. **赛事页、战队页**写着「资料不完整（缺少游戏 ID、联系方式）」「请先在个人中心添加至少一个游戏 ID」，**没有去补全的链接**（116 给内战报名、个人报名页、申请页加过，这两处漏了）
3. **第一次投稿**点「投稿」直接进 Wagtail 的新建页：「保存草稿」「更多动作 → 提交给内容审核」这些按钮、「推广」「设置」两页一堆 SEO 字段，没有任何说明

## 本轮范围

1. 验证邮箱后来到「基本资料」，一句欢迎和下一步（`AccountAdapter.get_signup_redirect_url`）；从别的页面带着 `next` 来的照旧回去
2. 赛事页的个人报名提示、战队页的申请提示加「去补全」链接（页面和片段共用一套判断）
3. 文章编辑页「投稿须知」：只给稿件要审核的人（不是超级管理员、内容编辑、认证作者）
4. 设计 3.1、5.4.3（v6.20）

## 验证

测试：注册确认后落在个人中心且有欢迎、确认码页上没有提前出现；带 `next` 时回原页；赛事页、战队页（整页和片段）有去补全链接；投稿须知投稿者看得到、内容编辑和认证作者看不到。变异逐条改坏。

## 验收标准

`AGENTS.md`「常用命令」那组全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
