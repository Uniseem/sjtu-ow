# 160 页脚「账号」一栏跟着登录状态

## 背景

继续自主推进。159 之后用截图工具在手机宽度看「我的报名」（157 加的日历订阅），页面本身正常，但页脚「账号」一栏写着「个人中心、登录、注册」：已经登录的人看到「登录」「注册」，点了会被跳回首页。页脚在模板里是写死的，因为预渲染的静态页对所有人一样。

站里已经有「静态页 + 登录后替换一块」的机制（13.13.3），页头的账号区就是这样，替换时一次请求取回页面上所有区块，多一块不多一次请求。

## 本轮范围

1. 页脚「账号」一栏做成替换区块 `footer-account`：访客（和静态页）看到「登录、注册」，登录的成员看到「个人中心、我的报名、我的战队」
2. Django 为登录的人直接渲染的页面，直接带上成员版
3. 设计 13.2.7 页脚一行（v6.52）

## 验证

测试：访客页面、预渲染出来的页面是登录、注册；登录后的页面和替换接口给出成员版，不出现登录、注册。变异逐条改坏。测试机截图看一眼。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
