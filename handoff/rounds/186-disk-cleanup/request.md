# 186 正式站服务器清理磁盘

## 背景

183 发现正式站服务器（169.58.217.180，上面还有 WordPress 等别的服务）磁盘只剩 19%，`/healthz` 的磁盘检查（剩余要大于 20%）一直报 503，`web` 容器显示 unhealthy。能腾地方的是 Docker 构建缓存（本项目 15.6 GB、另一个项目 4 GB），只清本项目的做不到，整体清属于 AGENTS.md 说的全局清理。用户 10-04：「清理下磁盘吧」。

## 本轮范围

`docker builder prune -af`（只清构建缓存，不碰镜像、容器、卷），看磁盘和健康检查；AGENTS.md、STATUS 记下来。

## 验收标准

健康检查恢复 200，`web` 回到 healthy，服务器上别的容器不受影响。
