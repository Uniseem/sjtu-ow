# 165 定时发布的文章可以「上线时通知全体成员」

## 背景

继续自主推进。158 让定时发布真正生效后，以内容编辑的身份接着走：周五晚上 8 点上线的招新公告，希望到点同时发邮件告诉大家。现在「通知全体成员」只给已经上线的文章（「发布之后才能通知全体成员」），编辑只能 8 点守在电脑前，等文章上线再点一次。

## 本轮范围

1. 已经「设置计划」、还没上线的文章，页面列表和编辑页的「更多」里出现「上线时通知全体成员」
2. 点进去还是那一页预览（主题、正文、现在会收到的人数），多一句「这篇文章 X 月 X 日 HH:MM 上线，到时自动发出；收信人数按上线那一刻算」，按钮「上线时发」
3. 点了以后记下来（同一篇还是只发一次：已安排的再点会提示「已安排在上线时通知」），不发信；文章上线的那一刻（定时发布或者有人手动发布都算）按当时开着「活动通知」的成员排队发出，人数记在发送记录上
4. 已安排的文章列表和编辑页不再显示这个按钮
5. 设计 10.4（v6.54）、README、后台手册内容编辑那一步

## 验证

测试：计划中的文章出现按钮、预览写上线时间；点了以后不发信、记录是「等上线」；到点上线（拨时钟跑定时发布）后发给成员、记录写上人数；再点会被拦；没设计划的草稿照旧不能发；上线后的文章照旧当场发。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级（演示站没配 SMTP，只看页面）。
