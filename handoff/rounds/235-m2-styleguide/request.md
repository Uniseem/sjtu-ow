# 235 M2 第五轮：设计体系样张

## 背景

234 把 `/_styleguide/` 登记成了一页标题。M2 的完成标准要这一页和现行站并排看起来一样（12 号文档 6.5、11.2）。现行站的样张在 `core/templates/core/styleguide.html`，不读数据库，只有能进后台的人看得到，别人是 404。

## 本轮范围

### 做

1. `/_styleguide/` 用现行站同一套类名把样张排出来：颜色、字体、标志、按钮、标签、图标、列表、表格、名片、表单、提示、正文、赛场横幅、首页块、评论。日期走上海时区，和现行站的 `ow_date` 同一套格式。
2. 访客和普通成员打开是 404，页面上不出现样张正文。`/api/session` 里 `admin: true` 的人看得到。邮件样张（`/_styleguide/emails/`）同样挡住，内容仍等 Go 把信渲染出来。
3. 样张用到的图标路径从现行站 `icon.html` 补进 `icons.ts`。

### 不做

- 邮件 HTML 对样（M7，要 Go 的 34 封信）。
- 把 `/static/img/` 接进新站的静态服务。占位图地址照现行站写，图本身还要等资产那一轮。
- 体积预算进 CI、字体。
- 正式站。

## 验收标准

测试机上 `pnpm test` 通过。三处变异先红再改回：样张对访客开放、拿掉「为战队报名」、名额格不再涂色。
