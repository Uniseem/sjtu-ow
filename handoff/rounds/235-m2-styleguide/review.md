## 验证记录

1. **重跑**：第一次 Vite 把模板里的 `src="/static/..."` 当成要打包的文件，测试机报 `ENOENT ... cover-07.svg`（日志 `20261008-201916-2ac03df`，退出码 1）。改成运行时绑定之后，日志 `20261008-202112-b1d2979` 退出码 0。site 33 条。
2. **改坏看红**：同一趟里三处（门永远放开、按钮文字改掉、名额格涂 0 格）各自变红，改回后基线仍绿。三条旧字符串各出现一次。
3. **浏览器**：`browser-check.mjs` 仍是 `BROWSER-CHECK-OK`。它不点样张（访客会话，样张本来就是 404）。样张正文是服务端渲染测的。
4. **对照现行站模板**：区块顺序、类名、例句、图标名单、颜色十六进制和 `core/styleguide.py` 的 `COLOURS` 一致。区块头组件不画 `01` / `COLOUR`，因为现行站的 `section_head.html` 也不画传进去的 index 和 en。
5. **日期**：固定在 2026-10-08 12:00（上海）时，样张的「三天后 19:30」是 `2026.10.11`、周日，和 Django 的 `ow_date` / `ow_weekday` 同一套。
