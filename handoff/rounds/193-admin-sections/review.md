## 自己挑的刺

- **高亮靠 CSS 的 `:has()`**：Chrome 105、Safari 15.4、Firefox 121 起支持。更老的浏览器侧栏会退回 Wagtail 自己的高亮（多半是「首页」），页面能用，只是高亮不对
- **标签条靠字符串插入**：在 Wagtail 的 `<div class="content">` 后面插。Wagtail 升级改了这段标记，标签条会整个消失但页面照常；有一条测试专门看它在不在
- **新加的后台页面要登记**：`PREFIXES` 里没有的网址不属于任何大类，侧栏不高亮；对不上任何标签的菜单项会单独挂在侧栏最后（不会丢）。写进了 README 和 AGENTS
- **「稿件」标签指向 Wagtail 的工作流报告**，那一页是英文翻译过来的通用列表，不如别的标签好用；本轮没改它的版式
- **标签上的件数每次打开审核页都查**：四个计数查询，和首页待办同一套函数
- 手机宽度看过一张内战列表，标签条横向滚动、左边让出了菜单按钮；别的页面在手机上没逐个看
