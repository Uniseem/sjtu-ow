## 范围

## 验收标准
1. 真实 Go 契约 page_size：20/21/40/41 条分页正确，加载更多沿用排序且不重复/丢页。
2. 顶层/回复点赞与取消赞、删除/隐藏确认取消与接受都实际调用正确接口。
3. 同组件切文章/排序、离开文章零异常；旧 GET/写后刷新不会覆盖新文章。
4. 评论表单慢响应不重复 POST；失败保留正文，成功清稿或关闭编辑/回复；列表和头部计数一致。
5. 整组 Go/Web、旧模板 SSR 参考、原 browser-check、新增评论浏览器回归全在测试机后台通过；关键规则做可编译变异并恢复。
6. 文章既有对拍缺口仍如实记录，不能因修评论就把内容组/全站标完成。每轮一个中文详细提交，推 main 看 CI，工作区干净。
