# 140 战队列表按缺的位置筛

## 背景

继续自主推进（用户 2026-10-04 再次设定目标：「自己继续推进完善。所有事务由自己决策」）。以找队的人的身份：我打支援，想找缺支援的战队。战队列表只能「只看招募中」；每支队 092 起标了缺的位置，但只能一张张卡片看过去，满员的也混在里面。

## 本轮范围

1. `/teams/?role=tank|damage|support`：招募中、没满员、缺这个位置（或没勾位置，表示哪个位置都要）的战队，也就是现在就能申请的
2. 标签栏加「缺坦克 / 缺输出 / 缺支援」，各带数量；数量和原来两个总数在同一次查询里算（列表页有「不能每队查一次」的测试）
3. 不认识的位置参数当作没筛；筛不到时说明并给创建战队的入口
4. 设计 7.6（v6.35）；README

## 验证

测试：缺支援列出 A（缺支援）、B（哪个都要），不列 C（缺坦克）、D（不招募）、E（满员）；数量对；当前标签标着；不认识的参数列全部；筛不到时的提示。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
