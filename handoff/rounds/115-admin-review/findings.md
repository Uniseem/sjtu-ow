# 115 后台和管理页面全面复查：发现的问题

用户（2026-10-03）：「后台界面之类的，全面 review 一遍，看看功能是否都做好了且合理，还有就是 ui 是否都符合当前的设计风格」。

**怎么查的**：

1. 本机建临时超级管理员，把后台菜单里每一项和列表里第一条对象的页面都打开一遍（状态码），无头 Edge 截图逐张看
2. 按五个后台角色（内容编辑、赛事管理员、内战管理员、认证作者、投稿者）各建临时账号，读后台侧边栏、逐个试打开自定义页面
3. 以队长身份截图个人中心、战队管理、创建战队、投稿、注销等管理页
4. 两个只读的子代理分别对照 `design.md` 第 14 章（及相关章节）审后台代码、对照 3、7、8、9、13 章审前台管理页代码

标「已核实」的是我自己跑过或读过代码确认的；标「待核实」的是子代理读代码得出的，修的时候先复现。

## 四、文档和实现对不上（改文档就行）

- 13.4 路由表少了 `/me/scrims/`、`/registrations/<id>/withdraw/` 和战队的几个 POST 地址
- 14.1 说页面、图片只给超级管理员和内容编辑，但认证作者（5.4 直接发布文章）和赛事管理员（选封面）都要用
- 设计把次要按钮叫 `c-btn--ghost`，代码里叫 `c-btn--quiet`
- 全站设置的备份字段不在 12.4.1 表里；`moderation_daily_limit` 的帮助文字说超额记「无法判定」，设计和代码都是排到第二天

## 五、要你定的

- 内容审核里的「直接处置」（第 21 条）做到什么程度：发邮件要求作者修改、清空战队简介、要求改昵称、停用账号，都放进复核页，还是只做发邮件
- 后台要不要换成交大红的配色（现在是 Wagtail 默认的紫色和青色）。我倾向不换：后台是给管理员的工具，Wagtail 自己的设计更新时不用跟着改
