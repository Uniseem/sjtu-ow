# 115 后台和管理页面全面复查，先修安全和会坏的

## 背景

用户（2026-10-03）：

> 后台界面之类的，全面 review 一遍，看看功能是否都做好了且合理，还有就是 ui 是否都符合当前的设计风格

## 本轮范围

1. **复查**：后台每个菜单项和对象页打开一遍、截图；五个后台角色各看一遍菜单和能进的页面；前台管理页截图；两个只读子代理对照设计审代码。结果写在 `findings.md`，分「必须修」「应该修」「界面和文字」「文档对不上」「要你定」
2. **修 `findings.md` 第一部分「必须修」的 11 条**（设计先改，记 v6.12）：
   - 发布过的赛事、有报名的内战不能在后台删除（删除按钮和删除页都拦）；网址里不存在的操作给 404
   - 后台「帐号」页不能改登录邮箱，去掉「名」「姓」和后台头像
   - 用户后台按 14.2 扩展：昵称、是否交大、停用原因代替「名」「姓」；编辑页列出游戏 ID、联系方式（需权限）、战队、功能规则；停用要写原因、自动取消待审批的入队申请；不能新建、删除用户
   - 报名审核列表加翻页链接；批量通过后的跳转只认站内地址；临时队伍的报名在服务端也不能从审核页驳回；导出只读导出的人的联系方式
   - 全站设置的备份密钥改成只写
   - 游戏 ID、联系方式页的 HTMX：新增出错不丢列表、「取消」不把整页塞进列表、删除被拦时有提示、删除按钮没有脚本也能用
   - 个人报名的游戏 ID 外键改成可空、删除时置空，删除已结束赛事用过的游戏 ID 不再出错
   - 战队后台不能新建、删除；编辑后重新生成页面、送 AI 审核；能改缺的位置；指定队长不能给已解散的队、不超人数、按昵称或邮箱搜人
   - 评论后台不能新建、删除；编辑页显示评论全文
   - 会删东西、发邮件的表单先确认（前台 15 处用 `data-confirm`，后台 3 处）

**不做**（下一轮起）：`findings.md` 第二、三部分；第五部分等用户定。

## 验证

每条修复有测试，变异逐条改坏；本机截图看改过的后台页；演示站升级、迁移。

## 验收标准

`AGENTS.md`「常用命令」那组全绿；变异全部被抓到；推送 `main`，CI 绿。
