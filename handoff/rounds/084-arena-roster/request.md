# 084 赛场与名册：赛事、内战、战队、成员

## 背景

081 起这几页已经是新配色（色调区块页头、白色数据卡、圆角票根），剩下 v2.0 的版式：英文眉标（TOURNAMENTS、SCRIMS、TEAMS、MEMBERS）、区块头的横线和借用评论计数的样式、侧栏资料表是一列发丝线、赛事「相关文章」上的粗线、内战报名统计的上下横线、成员页「共 N 位成员」被拆开的间距和发丝线编号名册。

## 本轮范围

**做**：

1. 四个列表 / 名册页去掉英文眉标；区块头的数量改用 `c-count`
2. 赛事、内战、战队详情页的侧栏资料表放进卡片（`c-facts--card`）；赛事「相关文章」用文章页的 `c-related`
3. 内战详情的三个位置统计改成三张小卡（`c-rolestats`）
4. 成员页：「共 N 位成员」不再被拆开；「全部成员」从发丝线编号列表改成成员小卡网格（`c-roster`），仍按加入先后编号（设计 6.3）
5. 设计 13.2.7 组件表同步

**不做**：报名、创建战队、申请入队、管理页这些表单页（085）；业务逻辑。

3. 内战位置统计。验证：`c-rolestats` 三格，没有 `border-y`
4. 成员页。验证：「共 N 位成员」在一个元素里；名册每人一张 `c-roster__item`，编号 `001` 起不变
5. 视觉：1280 截图、手机 375 无横向溢出
