# 180 队长停用后，战队自动改成暂不招募

## 背景

继续自主推进，接 178 报告「没做」里留的一条。178 让队长停用了的战队不能申请（`can_apply` 返回「等管理员指定新队长后再申请」），但战队列表、首页的战队卡片、战队主页页头、成员个人页、搜索结果都还写着「招募中」，「招募中」筛选和按位置找队也照样列出它。找队的人点进去、填好申请才被告知不行。

## 做法

在源头改：停用一个账号时，把他当队长、还没解散、正在招募的战队改成「暂不招募」。显示招募状态的地方都读 `is_recruiting`，跟着就对了，不用在每个列表里多查一次队长的状态（那样战队列表、首页、成员页、搜索各要加一个子查询）。

新队长接手后（站长「指定队长」或原队长复用后转让）自己在管理页重新打开招募。原队长的账号被恢复时也不自动打开：停用期间可能已经换了队长、或者队里的情况变了，由队长决定。

## 本轮范围

1. `teams/services.pause_recruiting(user)`：他当队长、没解散、正在招募的队改成暂不招募，重新生成这些战队页和战队列表；返回改了的队
2. `accounts/services.after_deactivation` 调它（后台停用账号时已经调 `after_deactivation`）
3. 后台停用后的提示里写明这些队已改成暂不招募
4. 设计 3.7（v6.62）

## 验证

测试：停用队长后他的队 `is_recruiting` 变成 False、战队列表的「招募中」筛选不再列出、战队页和战队列表重新生成；他只是队员的队、已经暂不招募的队、已解散的队不受影响；后台停用（用超级管理员走编辑页）提示里写了暂不招募。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
