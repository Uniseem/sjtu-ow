# 081 设计体系 v3.0：Material 3、磨砂顶栏、校徽

## 背景

2026-09-26 用户看了 074–079 做的 v2.0 前台（深色页头、全站直角、发丝线、票根切角），结论是「很难看，一点也不像正规的官网」。之后在本会话里看了 13 版首页样稿（A–M，放在会话临时目录，不进仓库），逐步定下：

- 整体风格和组件参照 Google 的 Android 开发者站（developer.android.com/design/ui）和 AOSP 站（source.android.com），也就是 Material Design 3 加 Google DevSite 的做法；适当结合玻璃拟态
- 首页版式定为 M 版：全屏浅色首屏、交大校徽水印、关键数字条、首屏里的近期安排卡和快捷入口磁贴，下面是资讯、通知公告、活动统计、战队
- 首屏不能整片交大红（L 版被否：「全红 + 玻璃不好看」），交大红只做强调
- 顶栏一进来就和首屏有区分，用和胶囊一样的磨砂白；往下滑变成胶囊并收到顶部，往上滑弹出，回到顶部恢复
- 近期安排只在首页首屏，不做全站悬浮
- **用校徽**：推翻 2026-09-19「不用校徽」。来源用户指定：github.com/weijianwen/SJTU-logo-banner 的 `SJTU_LOGO/SVG/sjtulogored.svg`，「正式的也用这个」

改动面很大，分轮落地。本轮先写设计文档，再换全站的底子：令牌、基础组件、页头页脚、样张页。首页的版式在 082 做，其余页面的版式在后面几轮做。

## 本轮范围

**做**：

1. `docs/design.md` 升到 v3.0：13.2 节整节重写（参考与取舍、原则、颜色、字体、形状与阴影与玻璃与动效、标志性元素、组件、页面骨架、实现规则），13.3 全站布局（顶栏的四种状态、浅色页脚），5.2 首页（M 版），12.4.1 新增 `founded_on`、`qq_group_url`，12.5.1 去掉焦点图，19.2 第 8、9 条，附录 D
2. `assets/css/input.css`：换成 Material 3 的色彩角色（交大红为种子色）；圆角、阴影、磨砂材质、缓动令牌；`on-night` 深色区块改为浅色的色调区块 `on-tonal`；按钮、标签、状态、表单、提示、面板、表格、票根、图块、名片、正文、评论等组件去掉直角、切角、斜纹，换成 Material 3 的形状和色调
3. 页头：磨砂白，整条 / 胶囊 / 收起 / 弹出四种状态，外部脚本控制（内容安全策略不允许行内脚本）；手机抽屉改浅色
4. 页脚：浅色
5. 校徽：`static/img/sjtu-emblem.svg`（裁掉 A4 画布的空白），`THIRD_PARTY_NOTICES.md` 登记来源和权利归属
6. 站点标志换成样稿里的红色圆角方块
7. 样张页 `/_styleguide/` 跟着换
8. 测试：`core/tests/test_design_system.py` 里写死 v2.0 规则的测试按 v3.0 改；新规则各有测试并做变异

**不做**：

- 首页版式（082）
- 赛事、内战、战队、成员、资讯、文章、个人中心、表单的版式调整（083 起）。本轮只保证这些页面换上新令牌和新组件样式后能正常显示、不出现深色残留
- 深色模式（19.2 第 9 条仍是单一主题；样稿里的明暗切换图标不做）
- 引入任何新依赖
