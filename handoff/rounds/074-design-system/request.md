# 074 设计体系与全站外框

## 背景

用户 2026-09-26 决定：**主色仍然是上海交大的深红色，其余的布局和设计全部推倒重来**；要参考其他游戏、社区、组织的官网，学它们的风格和巧思，给首页、子页和各个模块设计前端风格，**形成一套完整的体系**。中途又强调：**放弃掉当前的设计，不要被影响，当前的设计完全不行**。

所以 065 照交大官网做的那套（红色页头、米色、宋体、印章标志、日期方块、玫瑰色日历、拱形卡片、楷体引用）一律不沿用。

体系分四轮落地，每轮一个提交：

| 轮次 | 内容 |
|---|---|
| **074（本轮）** | 设计文档 v2.0；样式表从空文件重写：颜色、字体、组件；全站外框（页头、抽屉、页脚、操作提示）；通用组件模板；图标；站点标志和网站图标；样张页 `/_styleguide/`；错误页 |
| 075 | 首页、资讯列表、文章页、普通页面、评论区、搜索结果 |
| 076 | 赛事、内战、战队、成员展示 |
| 077 | 个人中心、登录注册（allauth）、报名和创建类表单；去掉 daisyUI 插件，加「模板里不再有 daisyUI 类名」的测试 |

原 STATUS 里的「074 上线前收尾」顺延到 078。
