# 046 提交信息改用中文

## 背景

用户 2026-09-18：「agents.md 里面加一条，以后的 commit 一律用中文」。

001–045 的提交信息都是英文。

## 本轮范围

做：

- `AGENTS.md` 硬规则加一条
- 设计 17.5 写着「提交信息说清楚改了什么、为什么改」，是提交信息规范的出处，同步改，附录 D 记版本
- `handoff/README.md` 流程第 7 步的示例是英文提交，换成中文
- `STATUS.md` 记进「你已经拍板的」；顺手把「下次开工」第 0 条（确认 045 的 CI）结掉——已经确认是绿的
- 本轮自己的提交就用中文

不做：

- 不改写历史提交。001–045 保持英文，改写要强制推送，而且会让报告里引用的提交哈希全部失效
- 代码注释、标识符不在这条规则里

## 验收标准

1. 文档里不再有英文提交示例
2. 本轮提交信息是中文，轮次号前缀和 `Co-Authored-By` 行保持原格式
3. 推送后 CI 全绿
