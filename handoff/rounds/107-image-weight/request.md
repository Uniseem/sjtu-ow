# 107 图片减重与懒加载

## 背景

用户 2026-10-03（和 106 同一句）：

> 你是不是没做懒加载？

查了模板：21 处画图片的地方，11 处已经 `loading="lazy"`，10 处没有。没有的里面 9 处是首屏的横幅、封面、首页大图卡和战队主页的队标（首屏的图本来就不该懒加载，懒加载反而会让它们晚出来），**文章正文里的图片**漏了。

真正拖慢的是图片本身太大。演示站成员页：

```
fill-400x400 214137B image/png
fill-176x176 49608B image/png
50 images on /members/, total 4276 KB
```

演示用的动漫插画是 PNG，Wagtail 的缩略图沿用原图格式，一张名片 200 多 KB，一页 4.2MB。宽屏上名片大多都在首屏里，懒加载也省不下来。

## 本轮范围

**做**（先改设计 13.2.5 / 13.10，记 v6.5）：

1. 缩略图一律存成 WebP（质量 80）：`WAGTAILIMAGES_FORMAT_CONVERSIONS` 把 PNG、JPEG 转成 WebP。WebP 带透明，透明队标照样透出底图
2. 分享图（`og:image`）仍用 JPEG：微信、QQ 等抓取预览图的程序对 WebP 支持不一
3. 文章正文图片懒加载
4. 测试：缩略图是 WebP、分享图是 JPEG；模板里每张图要么懒加载、要么属于首屏的那几类
5. README：升级到这一版后清掉旧缩略图（`wagtail_update_image_renditions --purge-only`），页面重新生成时按新格式生成
6. 演示站：升级（连同 106）、清旧缩略图、全量生成，量成员页的图片总量

**不做**：响应式多尺寸（`srcset`）；原图压缩（原图只在后台用）。

## 验证

测试、变异；演示站前后对比成员页图片总量。

## 验收标准

`AGENTS.md`「常用命令」那组全绿；变异全部被抓到；推送 `main`，CI 绿；演示站成员页图片总量明显下降。
