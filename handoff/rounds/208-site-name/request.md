# 208 站点名称改成 SJTU-OW

## 起因

用户 10-05（发完 SMTP 测试信以后）：「哦对，站点名称使用 SJTU-OW」。问了改到哪个范围，选「全站的名称都换」：页头的「交大守望先锋」、浏览器标签页上的「上海交通大学守望先锋社区」、分享卡片、邮件落款等全部改成 SJTU-OW。

现在网站在三种写法之间：简称「交大守望先锋」（页头、页脚、邮件页头、手机桌面图标名）、全称「上海交通大学守望先锋社区」（每页标题后缀、首页大标题、页脚 ©、邮件落款和页头小字、账号邮件正文、分享卡片的站点名、Wagtail 站点名）、发件人「SJTU 守望先锋社区」和主题前缀「[SJTU OW]」。

## 要做的（设计 13.2、10.3、附录 B，v7.12）

1. **凡是当名字用的地方都写 SJTU-OW**：页头和页脚的站名、每页标题后缀（「赛事 · SJTU-OW」）、首页首屏大标题、页脚 ©、手机桌面图标名（manifest）、分享卡片的站点名、Wagtail 的站点名、后台标签页和 Wagtail 底层后台的名字、错误页和维护页、邮件页头站名、邮件落款、账号邮件（验证码、找回密码）正文里的站名、发件人名称、主题前缀（`[SJTU-OW]`）、日历订阅的标识
2. **说明它是什么的句子留着**，让不认识缩写的人看得懂：首屏那句简介、页脚说明（改成「SJTU-OW 是上海交通大学守望先锋玩家的社团网站……不是上海交通大学官方网站」）、页面描述的默认值、邮件页头站名下面那行小字、AI 审核提示词里说网站是什么
3. **已经存在数据库里的**：全站设置的发件人名称、主题前缀如果还是原来的默认值，迁移改成新的（站长自己改过的不动）；Wagtail 站点名同样
4. 首屏大标题原来是两行中文（第二行橙色），改成一行「SJTU-OW」，「OW」橙色
5. 错误页和维护页改了模板要重新生成 `deploy/error_pages/`（在测试机上生成，拿回本机提交）
6. 不改：用户协议、隐私政策、关于我们这些**页面内容**（在数据库里，站长在后台改；里面的运营方名称本来就是【】待填）；样张页里示例赛事的名字；字体预览示例文字改成以 SJTU-OW 开头

## 验收

- 前台、后台、邮件、错误页里当名字用的地方都是 SJTU-OW，搜代码里旧名字只剩说明句和历史记录
- 数据库里没改过的默认值跟着变，改过的不动
- 规则拆掉就红（有一条测试数前台每页的标题后缀和页头站名）；整组检查、三个浏览器走查通过
