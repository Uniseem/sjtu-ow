# 090 封面占位图：文章和赛事没有封面时自动用本站画的插图

## 背景

2026-10-02 用户在本机看演示数据时，助手用 Pillow 程序生成了几张抽象占位图（山峦、夜景天际线、几何图形）当封面。用户说：「当前这些图片的风格我很喜欢。多设计并且生成一些。当具体的页面没有手动设定封面时自动用这些随机占位。」

现状（设计 v4.0，13.2.5）：文章、赛事没有封面时是 `surface-2` 的灰块，中间写分类名或赛事名；赛事横幅退回成没有图的素色条，首页大图卡没有图。

## 本轮范围

**做**：

1. 设计先改（v4.1）：13.2 约束后补说明、13.2.1 第 1 条、13.2.5 表和新的「占位图」一节、13.2.6 `c-stage`、13.2.8、5.2 文章页封面，附录 D 记一行
2. `core/placeholders.py`：用纯 Python 画 SVG。保留用户看过的三种场景，再加六种（海面、沙丘、极光、舞台灯光、星球、松林），每种四套配色共 36 张
3. `manage.py render_placeholders` 写到 `static/img/placeholders/`，文件提交进仓库
4. 「随机」做成**按对象 ID 固定取一张**：同一篇文章、同一项赛事永远是同一张，卡片、详情页、预渲染的静态页一致；相邻 ID 不撞场景，同 ID 的文章和赛事不撞图
5. 用在：文章卡片、文章头图、赛事卡片、赛事横幅、首页大图卡。上传了封面就用封面
6. 样张页列出全部占位图；删掉不再用的 `c-media__none`
7. README、AGENTS.md 写上新命令

**不做**：

- 首页首屏（校徽底）、战队队标（首字）、内战和战队横幅（素色条）保持原样：用户说的是「封面」
- 分享图不用占位图（SVG 多数平台不认，仍用默认分享图）
- 演示数据不进仓库；本机演示库里清掉上一次手动上传的「占位图 · 」封面，好看到自动效果
- 不新增依赖

## 任务和验证

| 任务 | 验证 |
|---|---|
| 生成器和 36 张文件 | 测试重画每一张逐字比对已提交的文件；文件集合和目录一致 |
| 命令 | 测试在临时目录跑命令：写全 36 张、删掉旧的 `cover-*.svg`、不碰别的文件 |
| 文件安全 | 测试：只有图形，没有脚本、事件属性、`<image>`、`href`、文字、外部 `url()`；每张小于 40KB |
| 场景 | 测试：9 种场景、36 张互不相同、相邻两张场景不同 |
| 取图规则 | 测试：同一对象同一张；ID 1–11 连续场景不同；同 ID 文章和赛事不同；没保存的页面（预览）也能取到 |
| 页面 | 测试：文章卡片、文章头图、首页资讯、赛事卡片、赛事横幅（不是素色条）、首页大图卡都用对应占位图；有封面的不出现占位图 |
| 变异 | 逐条把上面的规则改坏，对应测试要红 |
