## 自己挑的刺

- **迁移里 import 了应用代码**（`content.legacy_body`，反向还用 `content.markdown`）。以后改这两个文件可能让老迁移的行为跟着变。README 和模块说明里写了「迁移要用，别删」；`legacy_body` 只服务迁移，以后基本不会动
- **图片地址写死在正文里**：上传后插入的是缩略图的 `/media/images/…` 地址，图片库里删掉这张图，正文里就是坏图。原来的图片块是按编号引用的，删图时 Wagtail 会提示「被引用」，现在不会。社团规模下可以接受，记在这里
- **b23 短链在渲染时联网**：第一次渲染（多半是预渲染或预览）去查一次真实地址，Wagtail 存起来以后不再查；查不到就当普通链接，不会报错
- **上传权限**：用户 10-04 说「图片上传权限应该是所有人都有的」。验证过邮箱的成员本来就在投稿者组（有权限）；补上了赛事、内战管理员两个组（他们可能不在投稿者组），有一条测试用没验证邮箱的管理员上传成功，另一条用只能进后台、没有任何图片权限的人确认会被拒
- `journey.py pages` 没跑（测试机连不上，本机没有 Chromium），后台编辑页的浏览器报错只在内置浏览器里看过文章和赛事两页
