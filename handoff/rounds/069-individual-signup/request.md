# 069 赛事个人报名（散人池）

## 背景

用户 2026-09-25 决定：赛事支持个人报名，没有战队的人（比如新生杯的散人）以个人身份报名，由赛事管理员编成只属于这个赛事的临时队伍。报名信息和内战一样（选游戏 ID、勾能打的位置），资格校验和战队报名的队员一致；散人名单在赛事页公开人数、昵称和位置。

这轮做「散人池」：报名、取消、名单展示、个人中心、账号侧的连带处理。管理员拖拽编队和临时队伍在 070。

## 本轮范围

做：

- 设计 v1.7：新增 8.8 节「个人报名与临时队伍」（8.8.1 本轮，8.8.2 写明 070 实现）；1.2、1.5、3.8、4.4、8.1、8.2、12.1、12.8.1、12.8.5、12.11、13.4、13.13.3、13.13.4、附录 D
- `Tournament.allow_individual_signup`（后台面板和筛选）；`IndividualSignup` 表（`game_account` PROTECT，和内战一致；`registration` 可空，070 编队时填）
- 服务：`individual_problems()`（开关、时间窗、`member_problems()`、`existing_roster_conflict()`）、`sign_up_individual()`（创建或更新）、`cancel_individual()`（截止前、未编入）；变化刷新赛事详情页
- 前台：`/tournaments/<id>/signup/`（GET 表单、POST）、`/tournaments/<id>/signup/cancel/`（POST）；赛事页「报名入口」槽位加个人报名分支（匿名分支不含表单）；赛事页「个人报名」区块（人数、昵称、位置）；`/me/registrations/` 加「个人报名」区
- 账号：删除游戏 ID 时未结束赛事的个人报名拦住；注销时删掉个人报名；导出含个人报名；改昵称刷新有个人报名的赛事页
- 测试：每条拒绝一条；名单不含游戏 ID 和段位；槽位和实时页一致；预渲染触发；静态页无 CSRF 无「退出」；账号侧四条；地址清单加两条

明确不做：编队页、临时队伍、退出队伍、邮件（070）；散人报名的段位要求（管理员看段位自己编，缺段位显示「未填段位」）。

本地检查全绿；新守卫逐个变异被抓到；CI 绿。
