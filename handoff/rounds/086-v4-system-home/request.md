# 086 设计体系 v4.0：从零重做的颜色、页头页脚和首页（M10 第一轮）

## 背景

2026-09-26，用户看过 v3.0 和当天十余版样稿（Material 3 严格版、液态玻璃、thyuu、守望先锋官网、Material You、在 M 版上改色和加玻璃），都不满意，决定：**之前所有前台设计作废，从零重做**，由 Claude 直接定一套，做出来再看；可以用游戏官方素材；深浅色跟随系统。

用户在这一天明确说过的要求是约束：深红为主色、其他颜色合理搭配、不能整片暖色；以内容为导向；不要画蛇添足的说明小字和小点；不要「AI 味」（渐变光斑、玻璃底、背景混色、水印光带、眉标、数字递增）。

之前没提交的 086（藏青配色、文章页居中）作废，改动已撤回。

## 本轮范围（M10 分四轮：086 体系和首页；087 刊物页；088 赛场和名册；089 个人中心、表单、评论、错误页）

**做**：

1. 设计文档 v4.0：13.2 节重写（约束、原则、深浅两套颜色、字号最小 14px、版式与动效、图片与官方素材、组件表、页面骨架、实现规则），13.3 节页头页脚，5.2 节首页，12.4.1 新增 `hero_image`，13.13.4 刷新事件，19.2 第 8、9 条
2. 颜色令牌：浅色写在 `@theme`，深色写在 `prefers-color-scheme: dark` 里覆盖同名变量；v3 的令牌名先做成指向 v4 的别名，让还没重做的页面也跟着换色
3. 页头改成不变形的实色条，去掉磨砂、胶囊、收起和 `motion.js`；搜索换成图标按钮；页脚加游戏图片版权声明；站点标志去掉金色小圆点
4. 首页重做：首屏图（全站设置上传）、数字条、近期（正在报名的赛事大图卡 + 本周内战列表）、资讯图片卡与公告、战队
5. 去掉滚动出现、数字递增、视差（`data-reveal` 等）
6. 错误页、样张页、README 跟着改
7. 本地开发库导入用户同意下载的 6 张官方图（只在本地 `media/`，不进仓库）

**不做**：资讯、文章、赛事、内战、战队、成员、个人中心、表单页的版式（087–089 轮）；这些页先靠令牌别名换色。
