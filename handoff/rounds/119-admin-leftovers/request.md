# 119 后台复查的剩余小项

## 背景

115 轮复查（`handoff/rounds/115-admin-review/findings.md`）「其他（小）」和第 29 条里还没做的。做完后复查只剩第五部分两件要用户定的事。

## 本轮范围

1. **操作记录**（设计 14.4）：后台自定义按钮做的事写进 Wagtail 操作记录，在对象的「历史」页和「报告 → 网站历史」里能查到谁、什么时候、做了什么：赛事的发布、标记结束、取消；内战的发布、标记结束、取消；战队的指定队长、解散；内战的保存上场名单、生成分队、保存分队；队伍编排页的保存
2. **稿件的 AI 判断**（设计 5.5.1）：内容编辑打开投稿的编辑页时，上面一块写着 AI 的判断（风险、类别、理由、引用原文、链到复核详情）；还没审完写「AI 还在看」；投稿者自己看不到
3. **排版设置的预览**（设计 13.12：「设置页面旁边显示预览」）：宽屏时预览放在表单右边、随页面滚动停在视野里；窄屏照旧在下面
4. **赛事人数下限**：整队报名的赛事，下限超过全站战队人数上限时**保存前**就在这一栏报错（原来是保存后才弹提示）；这一栏的说明里写出当前的全站上限。个人报名的赛事不受这条限制（临时队伍不受战队人数上限约束）
5. **逐行查询**：用户功能规则、用户组功能限制两个列表（每行多查用户、组、操作人）；队伍编排页（每个散人查一次是否已在别的名单里）；投稿者首页的「我的投稿」（每篇稿件查一次审核状态）。改成一次取出，测试比较 2 行和十几行时的查询数相同
6. **自定义后台页面的写法统一**（#29）：状态切换按钮和翻页链接现在每页各写一遍（内容审核、头像审核、报名审核、静态页面），抽成两个公用片段
