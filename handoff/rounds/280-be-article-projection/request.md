## 验收标准

1. 真实文章 API 输出逐字段核对；作者正常/停用/空作者、头像本图/默认池/位置目录/空池，不暴露邮箱、联系方式。
2. 同栏目相邻文章按首发时间选，分类可以不同；跨栏目、同时间、草稿、受限文章排除；无首发日期上下篇 null。相关文章同分类排除自己，按首发/最近发布倒序最多三篇；无分类按 NULL 分类处理。
3. 评论计数按旧 thread 的顶层规则，访客与管理员身份对应可见性，包括存活回复墓碑，不把回复或已删且无存活回复的顶层算入。

5. 默认封面包含子目录、按图片 ID 排序，用文章 ID、赛事 ID+13 模池大小；重复导入保留原编号和父子关系。已存库迁移保留原行，新列默认 NULL。
6. 测试机后台专项、可编译变异、apigen、整组通过；文章四组合对拍收集实际差异，不因后端完成就标整页完成。report/review/STATUS、中文提交、推 main 与对应 SHA 的 CI。
