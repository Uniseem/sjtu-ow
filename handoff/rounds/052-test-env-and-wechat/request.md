# 052 测试环境横幅与禁止抓取；微信内置浏览器提示

## 背景

用户 2026-09-18 定了：测试机（`185.99.135.224`）上的部署**算测试环境**。设计 16.10 对测试环境有两条要求，043 核对时发现都没实现：

> 测试环境设置 `robots.txt` 禁止所有抓取，页面顶部显示「测试环境」横幅，避免被误当成正式网站

另外 16.9 的（**默认**）条目，050 规划时发现也没实现：

> 在微信里打开时，页面顶部提示「点右上角菜单，在浏览器中打开」

部署到测试机之前要先有这两样，否则测试机上的站会被搜索引擎收录、被当成正式站。

## 任务

1. 新增环境变量 `TEST_ENVIRONMENT`（默认关）。打开时：
   - `/robots.txt` 只返回 `User-agent: *` 和 `Disallow: /`，不再给 sitemap
   - 所有前台页面顶部显示「测试环境」横幅，**预渲染出来的静态页也要有**
2. 微信内置浏览器提示：**公开页面是预渲染的静态文件，服务器看不到访客的浏览器**，所以只能在浏览器里用脚本判断（`MicroMessenger`）。提示默认隐藏，判断是微信才显示
3. CSP 不许内联脚本，判断写进现有的 `static/js/app.js`
4. 设计 16.3 环境变量表加 `TEST_ENVIRONMENT`，附录 D 记版本；`README.md`、`.env.example` 同步

## 验收标准

1. 测试：打开和关闭 `TEST_ENVIRONMENT` 时 robots 和横幅各自正确；页面里有默认隐藏的微信提示
2. 每条新规则变异确认测试会红
3. **微信提示在真浏览器里验证**：普通浏览器不显示，把 UA 改成微信的显示
4. 本地四项检查干净，推送后 CI 绿
