# 236 M2 第六轮：内容安全策略和体积预算

## 背景

12 号文档 6.9 规定前台的内容安全策略，以及首页壳 gzip 后不超过 300 KB、其中脚本不超过 120 KB。策略字符串现在少了 `frame-src`，体积只在报告里写过，超了不会让检查变红。

## 本轮范围

### 做

1. 策略字符串和 6.9 逐字一致，包括 `frame-src 'self' https://player.bilibili.com`。检查里钉住这句话，改松（`unsafe-inline`、`unsafe-eval`）或少一段都会红。
2. `pnpm test` 在构建之后量首页壳：渲染出来的首页 HTML，加上入口脚本和它静态带上的样式、预加载脚本，各自 gzip。脚本合计超过 120 KB，或 HTML + 样式 + 脚本超过 300 KB，检查失败。按路由拆出去的块（样张）不算进首页。

### 不做

- 字体（D4）、把 `/static/img/` 接进来、并排截图。
- 正式站。Playwright / WebKit 不在这轮。

## 验收标准

测试机上 `pnpm test` 通过（整组带上）。两处变异先红再改回：拿掉 `frame-src`、把脚本上限改成 1 KB。
