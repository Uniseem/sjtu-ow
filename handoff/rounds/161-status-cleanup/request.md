# 161 STATUS 里过时的部分改到现在的样子

## 背景

160 之后想找下一处要完善的地方，把 `handoff/STATUS.md` 从头读了一遍。每轮更新的头部和轮次表是新的，但中间几块停在 089 前后：

- 「现在该谁动手」最后几段：「**你**：③ 升级测试机」、「测试机：185.99.135.224（域名 …），测试环境已经部署并在运行」。实际上 128 起测试机换成 `2a0e:6a80:3:9c7::`、只跑检查，185 那台不用了；域名 10-04 起给了演示站 169.58.217.180
- 「下次开工的第一件事：上线计划」开头一大段是 078–089 写的「合并分支、升级测试机（要你来做）」：从 066 升级到 089 的命令、迁移清单、升级后检查。那台机器不用了，部署也一直是我在做
- 「你那边」：让你在「测试机」上备份密钥、建超级管理员，命令里是旧的 Compose 项目名
- 「还没定的」：064 提的「预渲染失败要不要提示」早已做进后台待办；019/025 的 Webhook 重试随 067 删掉开放 API 一起没了

STATUS 是唯一记进度的地方（AGENTS.md），接手的人照着过时的步骤做会出错。

## 本轮范围

只改 `handoff/STATUS.md` 里上面这几块，写成现在的样子：两台机器各干什么、演示站上你还要做的事（建超级管理员、配 SMTP、备份密钥，演示站上实际查过：超级管理员 0 个、SMTP 未填、异地备份未填、AI 审核密钥未设）、上线前还没定的事。轮次记录和「你已经拍板的」不动。不改代码。
