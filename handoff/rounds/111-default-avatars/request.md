# 111 默认头像池

## 背景

用户（2026-10-03）：

> 以及成员未上传头像时的默认随机头像池也去收集一下（这个要求是英雄的动漫大头贴）

现在没有头像的人显示底图加首字（细节 2.2）。用户要的是：没传头像的人，从一组英雄大头贴里分到一张。

**素材**：官网英雄列表页每个英雄有一张 256×256 的头像（透明背景，53 个英雄），是游戏美术风格的 3D 立绘头像。手绘动漫风的官方大头贴没有公开下载的地方：游戏里的玩家头像、喷漆只在客户端里；守望先锋 Wiki 要过 Cloudflare 的人机验证（不去绕）；网上搜到的 Q 版、动漫风大头贴都是同人画师的作品，版权是画师的，不用。所以本轮先用官网这 53 张，图库做成后台可以换的：以后社团有了授权的动漫风头像，传进去替换就行。

## 本轮范围

**做**（先改设计：细节 2.2、2.3 加 2.4，`design.md` 13.2.5 表、13.2.7 `c-avatar`、3.5 表，记 v6.9）：

1. **图库**：Wagtail 图片集合「默认头像」（`init_site` 建），和默认封面一样子集合也算
2. **谁用**：没有头像的人按 `ID mod 张数` 取一张，同一个人在哪儿都是同一张；**停用和注销的账号不用**，照旧底图加首字（注销的人不该看起来像个活跃成员）；图库空着时也是底图加首字
3. **哪里**：所有画头像的地方（都走 `components/avatar.html`）和成员名片的大图
4. **速度**：一页只查一次图库（上下文处理器，惰性），缩略图跟着取；人多不增加查询
5. **刷新**：图库加图、删图、图移进移出时全站重新生成（和默认封面同一个合并机制）；账号停用、恢复时重新生成显示这个人头像的页面（头像会在图和首字之间换）
6. 本机和演示站导入 53 张官网英雄头像。演示站的 40 个演示用户都有动漫插画头像，看不到默认头像；**不动他们的头像**（用户选的），只在报告里说明，问用户要不要拿掉一部分

**不做**：头像上传（细节 2.3「以后」）；按主位置给对应英雄的头像（以后可以考虑）。

## 验证

测试：没头像的人取到图库里那张、同一个人各处一致；有头像的用自己的；停用、注销的用首字；图库空着用首字；子集合里的图算；名片大图也用；列表查询数不随人数涨；图库变化触发全站生成；停用、恢复刷新页面；`init_site` 建集合。变异逐条改坏。

## 验收标准

`AGENTS.md`「常用命令」那组全绿；变异全部被抓到；推送 `main`，CI 绿；演示站和本机有「默认头像」图库。
