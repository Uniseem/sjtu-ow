# 123 活动通知：新赛事、新内战一键群发

## 背景

用户（2026-10-04 睡前）：「比如你是管理员，发布了新的比赛，希望所有人都收到消息，能通过邮件一键发送吗？」现在不能：赛事、内战发布后只有已报名的人会收到和自己有关的信（取消、提醒），没有办法通知全体成员。设计 10.2 还写着「第一版不提供退订，只发和用户直接相关的重要通知」，群发必须能退订，所以先改设计（v6.19，新增 10.4）。

## 本轮范围

1. **成员的开关**：`User.accepts_announcements`（默认开）；个人中心「账号安全」加「邮件通知」一栏可以开关；导出个人信息里包含它
2. **退订链接**：每封群发信底部「退订活动通知」，链接带签名、不用登录，打开后确认就关；信头 `List-Unsubscribe`、`List-Unsubscribe-Post`，邮箱客户端的一键退订（POST）也能用
3. **发送**：发送记录（类型、对象、主题、操作人、时间、人数），同一场只能发一次；收信人是在用、邮箱已验证、开着开关的成员，限交大的只发交大成员；后台任务逐人发信；没配 SMTP 时不能发
4. **入口**：赛事、内战发布确认页上「同时通知全体成员（N 人）」；发布后在列表「更多」里「通知全体成员」，先看预览（主题、人数、正文）再确认；发过的显示「已于某时通知 N 人」
5. **信**：照 10.3，「新赛事：赛事名」「新内战：内战名」，写时间、报名截止、报名方式，按钮「查看并报名」；进邮件样张页
6. **文档**：设计 v6.19（已改：10.2、10.3、10.4、12.3.1、14.2、3.8）；README；隐私政策草稿说明活动通知和怎么关

## 验证

测试：收信人筛选（停用、未验证、关了开关、限交大）；同一场只发一次；没配 SMTP 拒绝；信有退订链接和信头；退订链接 GET 确认、POST 关掉、一键 POST 也能关、篡改的链接无效；个人中心开关；发布时勾选会发、不勾不发；没有赛事权限的人发不了。变异逐条改坏。

## 验收标准

`AGENTS.md`「常用命令」那组全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
