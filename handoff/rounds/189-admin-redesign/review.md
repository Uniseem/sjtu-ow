# 189 复核结果（自查）

## 结论

自查通过。后台换成了前台的颜色、字体、圆角和站点标志，深浅色都有；菜单从四十多个入口减到每个角色只看到自己那几项，常用的一点就到；首页从文字清单变成问候、快捷按钮和待办卡片。

## 判断里最没把握的

1. **改的是 Wagtail 的变量，不是它的组件**：Wagtail 升级时如果改了变量名，部分颜色会退回它自己的。令牌测试只保证我们抄的值对，不保证 Wagtail 还在用这些变量名。升级 Wagtail 后要看一眼后台
2. **隐藏的入口**：报告、文档、站点、重定向、工作流不进菜单，网址照样能开。站长偶尔要用（比如看锁定的页面）就得记网址；操作记录挪进了设置
3. **菜单项的序号是改在共享对象上的**：Wagtail 的菜单项注册一次、各请求共用，排序后改 `order` 等于全局改。每次请求都按同一张表重排，结果一样，但以后别处如果依赖原来的序号会受影响
4. **「文章」只链到资讯栏目**：以后如果加了别的文章栏目，要在这里加，或者改成列出所有文章的页面
