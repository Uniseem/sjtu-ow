# 189 后台重做（一）：外观、菜单、首页

## 背景

用户 10-04：「现在这个后台非常不好看，而且逻辑冗余，眼花缭乱的，后台也重新设计吧，遵守前台的设计风格，且以使用为主」（「我说的是管理后台」）。

在本机开发站以超级管理员看了一遍（没有密码，直接生成会话）：

- **外观**：Wagtail 原装的紫色侧栏、鸟标、青绿色按钮，和前台的交大红、浅灰底、圆角是两套
- **菜单**：第一层 页面、图片、社区（8 项）、成员分组、文章分类、文档、后台手册、用户（5 项）、报告（5 项）、设置（7 项）、帮助（3 项），一共四十多个入口。文档一个都没有；报告、帮助、设置里的站点 / 重定向 / 工作流社团用不上；常用的赛事、报名审核要先展开「社区」；写文章要「页面 → 根目录 → 首页 → 资讯 → 添加子页面」
- **首页**：Wagtail 的站点摘要（26 个页面、478 张图片、0 个文档）、页面搜索框、账号小卡，下面待办和上线清单是两段文字清单

设计 14.1 原来写着「后台用 Wagtail 默认的配色」（用户 10-04 早些时候定的），这次用户改了主意。

## 本轮范围

1. 外观：`static/css/admin.css` 把前台令牌对到 Wagtail 的语义变量（深浅色都有），字体、圆角；左上角换站点标志
2. 菜单按设计 14.1（v6.67）重排：首页、文章（直达资讯栏目）、文章分类、评论、赛事、报名审核、内战、战队、成员分组、内容审核、头像审核、图片、活动数据、网站页面、用户、设置、后台手册；文档、报告、帮助和设置里用不上的几项不进菜单
3. 后台首页：问候和快捷按钮；待办改成卡片；上线清单整理；去掉 Wagtail 的摘要、搜索框、账号小卡和自带面板
4. 列表页和编辑页的细节（表单分组、精简文章编辑页）下一轮做

## 验收标准

各角色（超级管理员、内容编辑、赛事管理员、内战管理员、投稿者）的菜单和设计一致；后台加载 `admin.css`，令牌值和前台一致；首页按角色显示快捷按钮、不再有 Wagtail 的摘要；浏览器里看过浅色和深色；整组检查全绿；推送 `main`，CI 绿；正式站升级。
