# 092 复核结果（自查）

## 结论

自查通过。自查时找到五处问题，当场改了（见下）。同一个人连着做的自查不能代替独立复核。

## 验证记录

- **重跑**：提交前把整组检查和变异重跑了一遍，输出贴在 `report.md`（31 处变异、32 项检查全部被抓到）。`check --deploy` 用 CI 的那组环境变量跑，输出 `System check identified no issues (0 silenced).`
- **对照用户原话逐条核对**：
  - 「类似 youtube 的那种全宽的设计」：列表页、首页 2000px 宽截图里卡片一行 6–8 张，没有两边大片空白
  - 「首页现在显得太空了……左边的字往中间靠一点」：首屏文字在左半边居中，标题随宽度变大；数字条居中
  - 「成员和战队展示……头像可以大一点」「图片的占比应该大一些，是图片主导的」：名片和战队卡上半部是正方形图，占卡片高度一半以上
  - 「文章的字全部靠左太难看了」：正文 44rem 居中、两端对齐
  - 「头像都改成方的」：`c-avatar` 圆角 8px（小号 4px），截图里核对；没有专门的测试查圆角
  - 「文章的封面改成类似截图这种」：封面铺满页头，字压在图上居中，一排信息小块，底边弧形
  - 「常用位置、个人宣言、段位怎么放」「现役和退役」「多个 title」：细节文档第 3、4、5 节各有一段，代码和测试按文档做
  - 「往我们的 svg 图片的那种设计方向上靠」：五张底图从占位图的场景函数生成，页脚山脊的颜色就是 night 三个令牌
  - 「这种页面，也要居中一些啊」：13 个看和操作的页面用 `l-container--narrow`，测试逐个模板查
- **在浏览器里核对**：无头 Edge 截了首页、成员（浅色、深色、390px）、战队列表、战队主页、文章、赛事详情、内战列表，1440 和 2000 宽。个人中心「基本资料」表单只有测试覆盖，没截图

**自查找到并改掉的**：

1. **战队卡人数拆成两段**：给数字单独套了 `font-numeric` 的 `<span>`，「1 人」被拆开，旧测试按文字找不到。改成整段一个 span
2. **队标像加了框**：第一版队标缩到 84% 放在底图上，演示队标是方形不透明的，四周露出一圈底图，像相框。改成铺满，文档同步
3. **文章卡署名没样式**：模板加了作者和阅读时间，样式表里漏了 `.c-media__byline`，截图里挤成一团。补上
4. **「我的战队」少一个 `{% endif %}`**：加退役记录时漏的，页面直接报模板语法错误。补上，并让测试打开这一页
5. **页脚山脊太平**：第一版起伏小、只有 3rem 高，截图里像一条灰线。加大起伏，桌面 5.5rem

另外两件和代码无关的：Bash 工具里用 heredoc 跑内联 Python 写文件，反斜杠少一层，几次把 `"\\n"` 写成了真换行，测试文件和占位图生成器都被写坏过，靠测试和 `render_placeholders` 比对发现；写进了 AGENTS 的坑。开发服务器改 Python 文件后又退出两次，重启就好。

## 发现的问题

必须修：无。

建议修：

- 成员页一页可能有几十张名片，底图都是静态 SVG、同一张反复用，理论上开销不大，但没在低端手机上看过
- 092 之前离队的人没有退役记录。要补只能让队长手动加，现在没有这个入口；先不做，看社团要不要

## 判断里最没把握的

1. **段位默认公开**：用户问「段位怎么放」，我理解为要展示。段位本来是填给内战分队用的，有人可能不想让别人看到，所以加了开关，但默认是开。隐私政策草稿已写上「默认公开，可以关」。社团如果更在意隐私，改成默认关
2. **退役记录在公开页不写原因**：主页只写起止年月，「自己退出」还是「被移除」只在管理页给队长看。理由是被移除对当事人不太好看
3. **个人宣言不许带链接**：防广告，但也挡掉了正常想留 B 站空间的人
4. **职务用一栏顿号分开**：没有改成后台多行输入，是为了不动表结构、后台照旧好填。缺点是写错分隔符（比如空格）会被当成一个职务
5. **段位 180 天算旧**：旧的段位变灰，悬停显示更新日期，不隐藏（赛季会重置，旧段位不准，但删掉又可惜）。180 天这个数是我估的，没有依据
