# 092 设计 v5.2：全宽、细节规格、图片主导的卡片

## 背景

091 推送后，用户 2026-10-02 到 10-03 在本机看站点，依次提了：

1. 「尝试一下类似 youtube 的那种全宽的设计，在现在这个设计的基础上改，这样每个部件都可以宽一些大一些」
2. 「目前效果还行。但是你配套没做好，首先首页现在显得太空了，要不然加元素，要不然左边的字往中间靠一点。然后底下的页面，特别是成员和战队展示，一个个框框之类的都可以重新设计，反正现在空间大，头像可以大一点，设计上也可以设计的漂亮一些。其他的文章页面也一样，你文章的字全部靠左太难看了」
3. 「头像都改成方的。然后文章的封面改成类似截图这种。就是各方面细节你都要考虑……比如成员展示，他的常用位置，他的个人宣言，他的段位怎么放？比如一个战队，如果有现役和退役，你要怎么处理？一个人如果有多个 title，你又怎么展示？所以我希望你先把这些东西单开文档，全部自己想一遍然后记录，把每个细节都处理好。自己写文档，自己做决策」（截图：封面图铺满页头，字压在图上居中，一排信息小块，底边弧形）
4. （做的过程中）「每个战队或者头像框的话，图片的占比应该大一些，是图片主导的。然后站点各个组件的设计，能不能往我们的 svg 图片的那种设计方向上靠一点」
5. （看了赛事详情）「这种页面，也要居中一些啊，现在这个中间一片空白，很难看」
6. 「提交并推送」

用户把细节的决定权交给了助手（第 3 条），所以本轮的设计决定都写在新文件 `docs/design-details.md` 里，附理由。

## 本轮范围

**做**（设计 v5.2，先写文档）：

1. `docs/design-details.md`：总则（宽屏、缺省、截断、数量上限、颜色和底图、可点、深浅色、隐私、插画风格）、头像与队标、个人资料三项、成员展示、战队、文章、首页、赛场、表单、数据改动、做和不做；`docs/design.md` 13.2 节指向它，相关章节同步
2. 全宽：页面最宽 1920px，卡片网格自动排列；看和操作的页面（详情、表单、个人中心、搜索、内战列表）整块居中 80rem；页头 1280px 起中间是搜索框
3. 首页：首屏左右两半各自居中、标题随宽度变大、数字条居中；「近期」两栏等高
4. 个人资料：个人宣言（30 字、一行、无链接、送 AI 审核、复核页可清空）、主位置 + 也能打、公开段位开关（默认开）；成员页和战队主页显示位置和主位置段位（所有游戏 ID 里取最高）
5. 成员页：名片图在上（底图 + 大首字），职务（一栏顿号分开可写多个）、宣言、位置与段位、战队；分组左右两栏；全部成员小卡
6. 战队：缺的位置；退役成员（退出、移除时记录，主页列出起止年月，本人或队长可删，重新入队删掉，注销时删）；战队卡图在上；主页队头是底图横幅、现役成员卡、退役列表
7. 文章：铺满页头的封面（摘要、作者、日期、更新于、阅读时间、字数、评论数，下沿弧形）、正文居中两端对齐、目录（3 个以上小标题）、作者卡、上一篇 / 下一篇；文章卡加作者和阅读时间
8. 插画风格：头像和队标圆角方形，画在五张静态底图上；页脚山脊；空状态配图
9. 导出个人信息、隐私政策草稿、README、AGENTS 同步

**不做**（理由见 design-details 第 11 节）：用户上传头像、个人主页、成员筛选、目录高亮当前位置、分享按钮、浏览量；内战详情不加段位。

## 任务和验证

| 任务 | 验证 |
|---|---|
| 位置与段位 | 测试：位置固定顺序、每个位置取所有游戏 ID 里最高、180 天变旧、主位置在前、开关关掉没有段位 |
| 资料表单 | 测试：宣言压成一行、有链接拒绝、超长拒绝、主位置不重复进也能打、开关没勾就是关 |
| 首字和底图 | 测试：跳过符号取字、全符号写「?」、按 ID 取五张之一；样式里每个类都有对应底图和加载前的颜色 |
| 退役 | 测试：退出、移除记录；回来删掉；注销删掉；只有本人和队长能删；主页列出年月不写原因；管理页写原因；我的战队列出 |
| 缺的位置 | 测试：只在招募中显示；表单保存 |
| 成员卡 | 测试：图在前、多职务拆开、超过 3 个写「+N」、超过 2 支战队写「等 N 支」、小卡职务优先、缺的行不出现 |
| 文章 | 测试：字数、阅读时间、标题锚点和目录门槛、封面信息小块、「更新于」、作者卡、上下篇、卡片署名 |
| 宣言审核 | 测试：送审、空的不送、复核可清空且只在宣言条目出现、改资料和段位刷新页面、私密段位不刷新、导出带上 |
| 底图和山脊 | 测试：五张不动、文件和生成器一致、山脊颜色就是三个 night 令牌 |
| 居中 | 测试：这些页面的容器都是 80rem 的那种 |
| 变异 | 把上面每条改坏，对应测试要红 |
| 截图 | 无头 Edge：首页、成员、战队列表、战队主页、文章、赛事详情，浅色 / 深色 / 手机 / 2000px |
