# 077 个人中心、登录注册和表单页；去掉 daisyUI

## 背景

074–076 把外框、内容页、赛场页换成了设计体系。剩下的是只对登录用户的页面：个人中心（`/me/` 下 7 页）、登录注册等 allauth 页面、报名和战队的表单页。这些做完，前台就没有 daisyUI 的类了，可以把过渡期保留的插件去掉。

## 本轮范围

**做**：

1. 个人中心骨架（13.2.8「个人中心」）：栏目头；桌面左侧编号菜单（当前项左沿红线），手机上横向标签；资料不完整的提示条（`c-notice`）
2. 基本资料、游戏 ID 与段位（每个 ID 一个面板：等宽的游戏 ID、三个位置的段位、更新时间、编辑 / 删除，HTMX 行为不变）、联系方式、我的战队、我的报名、我的内战、账号安全、注销
3. 登录、注册、验证码、找回密码、改密码、改邮箱、退出等 allauth 页面：窄栏表单，栏目头 + `c-field`
4. 表单页：为战队报名（每个队员一行选游戏 ID）、个人报名（位置用 `c-choice`）、报名详情（状态、名单快照表、状态历史）、创建战队、申请入队、战队管理（待审批的申请、成员、资料、解散）
5. 去掉 daisyUI：`input.css` 删插件和过渡主题；设计 13.2.9 和 README 的过渡说明删掉
6. 测试：前台模板里不能再出现 daisyUI 的类名（扫描全部前台模板）；个人中心菜单编号和当前项；游戏 ID 面板；报名状态形状
7. 新组件 `c-panel`、`c-link` 写进设计 13.2.7 和样张页

**不做**：Wagtail 后台的页面（后台不加载前台样式表，本来就没用 daisyUI）；业务规则。

## 验收标准

- 整组检查全绿；新规则做变异
- 1280 和 390 截图：个人中心各页、登录、注册、为战队报名、报名详情、战队管理
