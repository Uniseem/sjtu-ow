# 071 站内搜索

## 背景

用户 2026-09-25 决定做站内搜索：文章、战队、成员、赛事与内战都搜；中文按子串匹配，不引入分词库，社团规模够用。设计 1.3 节原来把站内搜索列在「第一版不做」。

## 本轮范围

做：

- 设计 v1.8：1.3 删「站内搜索」；2.3 加 `search` 应用；新增 13.16 节「站内搜索」；13.4 路由 `/search/`；15.2 限流；附录 C（每类最多 20 条、每 IP 每分钟 30 次）；附录 D
- 新应用 `search`：`services.py` 四个提供方（文章：已发布，标题、摘要、正文；赛事与内战：已发布和已结束，标题、说明；战队：未解散，队名、简介；成员：成员展示页上的人，昵称），纯 ORM `icontains`，查询按空白拆词取交集，每类最多 20 条，摘录取首次命中前后各 40 字并去标签
- `/search/?q=` 实时渲染（带参数的公开页面本来就不预渲染，13.13.1）；页头搜索框（GET 表单，无 CSRF，预渲染页可含）；限流用 `core.ratelimit.over_limit`
- 测试：每类可见性规则各一条（草稿、已解散、停用用户、已取消的赛事不出现）；多词取交集；摘录；空查询和超长查询；限流；页面无 Alpine 表达式；地址清单加 `/search/`；附录 C pin

明确不做：分词、拼音、相关度排序（按更新时间倒序）、搜索统计、结果分页（超过 20 条提示缩小范围）。

## 验收标准

本地检查全绿（每条命令单独看退出码）；新守卫逐个变异被抓到；CI 绿。
