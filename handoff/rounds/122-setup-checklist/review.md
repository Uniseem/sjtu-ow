## 结论

自查通过。新站长照 README 部署后，`init_site` 和后台首页都会告诉他还差什么；最要命的「没配邮件就没人能注册」现在是清单里第一项。

- **清单**：邮件从必做变成已完成（填了 SMTP）；协议有【】时未完成、填好后完成、清空后提示「还没有正文」；AI 三种状态的说法；备份要密钥和开关都有；内容编辑组有人才算完成；测试环境开关；内容编辑看不到清单
- **init_site**：跑完协议、隐私政策有草稿正文，输出里有「接下来」；社团改过的协议再跑一次不被覆盖
- **试一下**：成功显示模型判断并计一次调用；401 提示密钥不对；没设密钥时页面写原因、不显示按钮，直接提交也只返回原因
- **演示站**：清单列出的就是演示站真实缺的东西
- **重跑**：14 处变异全部被抓到
