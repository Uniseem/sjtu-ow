# 122 站长上线清单

## 背景

用户（2026-10-04 睡前）：「继续做，不断完善每一个细节。你可以假定自己有不同的身份，比如你是管理员，要初始化站点，然后配置 ai 等东西，期间有没有什么功能不完善的？……你要自己假定自己的各种身份，去思考每一个细节，然后自己做决定，慢慢修改。」

这一轮是「站长第一次部署」这个身份。在本机建了一个空库，照 README 走 `migrate`、`init_site`、建超级管理员，再看各页面：

- **用户协议、隐私政策、关于我们三页是空的**（只有标题和日期），注册时却要勾「我已阅读并同意用户协议和隐私政策」。草稿在 `content/legal/`，要另外记得跑 `load_legal_pages`
- `init_site` 跑完只说做了什么，不说接下来要做什么
- 后台首页对站长没有任何提示：**没配邮件就没人能注册**（注册要验证邮箱），但哪里都不提醒；AI 审核要在环境变量里设密钥，后台只写「开关关着」，没设密钥时也这么说，误导人；设好密钥后没办法确认能不能连上

## 本轮范围

1. **后台首页「上线清单」**（只给超级管理员）：逐项检查只有站长能做的配置，分必做和建议，每项写缺什么、链到去改的地方，做完的收起来
   - 必做：邮件（SMTP 服务器和发件地址）；用户协议、隐私政策有正文、没有剩下的【】
   - 建议：AI 审核（区分没设密钥和开关关着）、异地备份（加密密钥 + 对象存储开关）、内容编辑组里有人、关于我们有正文、站点简介 / QQ 群 / 成立日期 / 首屏图、默认封面和默认头像图库有图、测试环境横幅关掉
2. **`init_site`**：用户协议、隐私政策是空的就填入草稿（调 `load_legal_pages`，有正文的不动）；最后列出「接下来」：建管理员、按上线清单配置、AI 密钥
3. **AI 审核**：「内容审核」页写清楚没在运行的原因（没设密钥 / 开关关着）；新增「试一下」按钮：发一句测试内容给 AI，显示判断或连不上的原因（401/403 提示密钥，404 提示模型或地址），开关关着也能试，算一次调用、不留记录
4. **文档**：设计 14.1、16.4、5.5.4（v6.18）；README

## 验证

测试逐项（必做、建议各至少一条从未完成变成完成）；内容编辑看不到清单；`init_site` 之后协议页有草稿、输出有「接下来」；「试一下」成功、密钥错误、没设密钥三种情况。变异逐条改坏。

## 验收标准

`AGENTS.md`「常用命令」那组全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
