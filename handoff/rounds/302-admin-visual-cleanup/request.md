# 302 后台和网页界面删减

## 背景

用户 2026-11-09：「目前感觉整个后台很杂乱，很多不必要的图片。网页什么的也有很多画蛇添足的小字，这些都不要」。基线为 `7a5be081`，开工工作区干净，已执行 `git pull --rebase`。

## 本轮范围

本轮由当前助手修改新栈后台、前台及共享样式，清除装饰图片、重复的标题层级、功能介绍和可由控件本身说明的帮助文字。用户随后要求更新 AGENTS，允许跨前后台连续修复关联问题；当前授权和规则调整见文末。先更新设计，再改页面。

保留图片库、选图、头像审核、已选图片预览等实际操作需要的图片，保留字段名称、保存状态、错误、权限和操作后果说明。保留用户维护的正文、栏目介绍和图片数据。不改 Go 业务代码、API 契约和冻结旧站，不新增依赖，不访问正式站或部署。测试夹具与协作规则的补充授权见文末。

## 任务

1. 空状态去掉风景插图，后台去掉重复身份图片、栏目眉标和未选图时的空预览框。通过浏览器核对空状态、账号菜单和选图。
2. 删减后台列表与表单的说明文字，精简必要的字段约束。字段、写操作及错误状态保持可用。
3. 去掉登录、注册的功能介绍侧栏，删去前台栏目页和搜索页的固定介绍。保留正文、实际状态和参与限制。
4. 更新设计与迁移差异。旧站不随本轮改动；已批准删除的图文不再要求与旧站逐字、逐像素一致，不据此改写历史验收结果。

## 验收标准

- 所有构建和检查先在测试机后台运行，输出落文件；先尝试测试机，无法连接时才能本机兜底。
- 提交前运行整组检查，再运行受影响的后台和前台浏览器检查。用虚构数据，在桌面和手机、浅色和深色检查主要改动并保存截图。
- 留下可重跑的本轮页面检查脚本。记录真实退出码，未运行项目写「未验证」。
- 一轮一个中文提交，沿用本地作者身份，署实际模型，推送 GitHub 和 GitLab，并检查该提交的 GitHub CI。
