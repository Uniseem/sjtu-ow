# 172 导出个人信息补齐，以后新加的表也漏不了

## 背景

继续自主推进。以想知道网站存了自己哪些信息的成员身份（设计 3.8，个人信息查阅和导出）：「导出个人信息」是 058 做的，之后加了很多带个人信息的表。对一遍发现评论（072）、点赞（073）、对本人单独设置的功能权限（比如被禁言和原因）都没在导出里。

在测试机上列出项目里每一个指向用户的字段，35 个：大部分已经导出，或者是「谁做了这个操作」（审核人、创建人、队长提交名单），或者是 Wagtail 页面的所有者和锁定人；真正属于本人、却没导出的就是上面三类。

## 本轮范围

1. 导出加三节：`comments`（文章、正文、时间、公开 / 已隐藏 / 作者已删除）、`comment_likes`（文章、时间）、`feature_rules`（功能、允许还是禁止、原因）
2. `accounts.services` 里写一份清单：每个指向用户的字段导出到哪一节，或者为什么不导出；测试数一遍库里的字段，和清单对不上就红
3. 设计 3.8（v6.56）

## 验证

测试：清单和库里的字段一致、导出里有清单写的每一节；三节的内容（含别人的评论不在里面）。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
