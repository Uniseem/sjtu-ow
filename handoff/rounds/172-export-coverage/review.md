# 172 复核结果（自查）

## 结论

自查通过。成员导出的文件里有了自己的评论和点赞、对自己的功能限制和原因；更要紧的是清单加测试，以后再加带个人信息的表，忘了写导出测试会红。

## 判断里最没把握的

1. **AI 审核记录不导出**：理由见报告。要是社团（或者法规）要求把「系统对我的内容做了什么判断」也给本人，就把 `moderation.ModerationItem.author` 从 `NOT_EXPORTED` 挪到 `EXPORTED`、加一节
2. **功能权限的原因照原样给本人**：管理员填原因时要知道本人能看到；后台功能权限页没有提示这一点，以后可以加
3. **只数了外键**：用户编号存在 JSON 或普通整数字段里的（目前没有）数不到
