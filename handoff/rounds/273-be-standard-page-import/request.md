# 273 普通页导入与元数据接口

## 背景
270 对拍发现普通页导入读错表，且错误被吞：关于、协议、隐私页在新站返回 404（BE-0）。普通页接口缺 SEO 与最后更新时间（BE-1）。依据 design.md 5.1–5.2、12 号文档 5.12 和 STATUS 的 BE-0/BE-1。

## 本轮范围
修 server/internal/content 的普通页导入、同文件错误传播、普通页元数据读取与接口；补回归和变异验证；使用测试机生成 API 契约。搜索与会话投稿资格留下一轮，不改前端页面或 pending-api.ts，不部署任何服务器，不改旧站。

## 任务
1. 从真实 content_standardpage 导入 ID、正文、发布状态、SEO、首次/最近发布时间；三个协议相关地址可通过 API 读取；草稿仍返回 404。
2. Query、Scan、行迭代、事务与 INSERT 错误必须报告；写入失败回滚该段，不能返回成功。
3. GET /api/page/{slug} 加 seo_title、search_description、last_published_at（空为 null，非空 RFC 3339），保持既有字段。
4. 重新生成接口契约；不修改前端归属文件。

## 验收标准
测试机后台运行内容回归、真实旧站种子导入到新库的普通页检查、针对性变异；重新生成 apigen 后取回生成物；整组 Go/Web 检查必须通过。自查按旧站模型核对；页面视觉对拍由 Claude 接入验收，未跑的明确记未验证。

真实种子导入补充：整组先通过，但完整导入因图片集合固定 key 与旧编号冲突中止（此前 INSERT 吞错掩盖了它）。本轮同时修复预置集合 key 的事务内迁移，沿用旧集合 ID，缺失内置集合补回；用编号置换和重复导入回归验证。
