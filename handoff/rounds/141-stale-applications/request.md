# 141 队长 14 天没处理的入队申请自动关闭

## 背景

继续自主推进。以递了入队申请的人的身份：队长不怎么上线，申请就一直挂在「待审批」，没有任何结果；我不知道该继续等还是去找别的队。设计 7.3 的「已取消」只有申请人撤回、战队解散、已经通过别的途径入队三种。

## 本轮范围

1. 待审批超过 14 天的申请，由每天 04:00 的 `cleanup_old_data` 关闭：状态「已取消」，原因「队长 14 天没有处理，申请自动关闭」（「我的战队」里会显示）
2. 每个被关闭的申请人收到「入队申请已关闭」，按钮去招募中的战队列表；可以再申请
3. `--dry-run` 只统计；命令输出这一项写「将关闭 / 已关闭」，不写「删除」
4. 放进现有的夜间命令，不用改两台服务器上的定时任务
5. 设计 7.3、10.2、16.5（v6.36）；README

## 不做

- 申请挂了几天后提醒队长：可以以后再加；队长本来就收到过一封

## 验证

测试：15 天的关闭、写原因、申请人收到、能再申请，13 天的不动；已经处理过的旧申请不动；试运行不改。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
