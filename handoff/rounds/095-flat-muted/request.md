# 095 试验：把占位图的扁平、克制风格用到整个界面（分支 claude/flat-muted-ui）

## 背景

094 推送后，用户 2026-10-03：

> 现在这个呢，很不错。我希望你新开一个分支，去尝试一下把现在这个 svg 的扁平风格（我不确定算什么，也许有点映像派？）以及它的这种比较克制比较淡的色调风格去应用到整个站点（就是ui那些东西），试一下吧

用户要的是**新分支上的试验**，所以这一轮不推到 `main`（`AGENTS.md` 硬规则 2 说直接推 `main`，这次用户明确要分支）。分支名 `claude/flat-muted-ui`，沿用 074–079 那次分支的前缀。

先读了占位图生成器和 16 张图：它们是扁平剪影风景插画，平涂的山、城市、沙丘一层叠一层，越远越淡越偏蓝灰（空气透视），天空柔和渐变加一团光晕。白天版（栏目页头）尤其淡：雾蓝、暖灰、沙色、灰紫。不是印象派，更接近游戏《Firewatch》海报那一路。

## 本轮范围

**做**（设计 13.2.2 记 v6.0 草案）：

1. 颜色：浅色、深色、夜色条三套令牌全换成从图里取的低饱和色（暖雾白底、深石板蓝字、砖红、沙杏、灰绿、雾蓝、赭黄；深色是夜景的深蓝灰）。对比度照旧 AA
2. 「克制」写成规则：所有颜色令牌和五张底图的彩度不超过 0.5
3. 地平线：带图的页头和详情横幅底边两道山脊剪影，远的是雾，用页面底色填；去掉下面的分隔线
4. 区块标题前的山形记号
5. 五张底图换成黄昏低饱和版；页脚山脊跟着新夜色
6. 错误页、维护页、样张页色板、邮件跟着换色

**不做**：封面占位图（36 张）和栏目页头的图本身不改，那是插画，用户说喜欢；字体、布局、组件结构不改。

## 验证

测试：彩度上限（令牌、底图）、地平线（遮罩、页面底色、没有分隔线）、远山是雾、标题的山形记号；原有的对比度、深浅色、占位图测试照旧。变异逐条改坏。截图浅色 / 深色发给用户。

## 验收标准

`AGENTS.md`「常用命令」那组全绿；变异全部被抓到；提交在分支上，推送分支，**不合并到 `main`**，等用户看过再定。
