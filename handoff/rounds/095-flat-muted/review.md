# 095 复核结果（自查）

## 结论

自查通过（分支上）。这是用户要的试验，好不好看由用户定；技术上全绿、对比度达标。自查时找到四处问题，当场改了（见下）。

## 验证记录

- **重跑**：整组检查和变异在提交前跑过，输出贴在 `report.md`
- **对照用户原话**：
  - 「svg 的扁平风格」：界面本来就是扁平的（没有阴影、没有立体按钮），这次加的是图里最有辨识度的两样：层叠的山脊（页头底边的地平线、标题的山形记号）和「越远越淡」（远山用雾）
  - 「比较克制比较淡的色调」：颜色全部从图里取；「克制」写成可测的规则（彩度 ≤ 0.5），旧的守望先锋橙和交大红都过不了
  - 「就是ui那些东西」：只动界面；封面和栏目页头的插画本身没改
- **截图**：无头 Edge，1440 宽，浅色 6 张（首页上下、成员、战队、赛事详情、文章）、深色 3 张（首页、成员、赛事详情），发给了用户

**自查找到并改掉的**：

1. **详情横幅底下一条灰带**：第一版远山是 50% 透明的页面底色，叠在深色图上成了一条脏灰色。改成从山脊往下由淡到浓的雾，截图里像图里的晨雾
2. **地平线下还有分隔线**：原来页头底边有 1px 线，山脊下面又一条硬线，去掉
3. **成员页太吵**：底图还是饱和的深红、橙、墨绿，和新的淡底打架。换成同样场景的黄昏低饱和版
4. **「克制」的尺子选错**：先用 HSL 饱和度，结果很浅的奶油色也算「饱和」。改用彩度（RGB 最大减最小），三个橙色值因此收了一点

## 发现的问题

必须修：无。

建议修：

- 封面插画（36 张）很多是深色、饱和的夜景，放在淡色界面里对比很强。要更统一，可以给卡片也做白天版（像栏目页头那样），工作量不小，先不做
- 每改一次 Python 文件开发服务器就卡死，这一轮重启了四次

## 判断里最没把握的

1. **交大红收成砖红**：用户 v5.0 定过「主色是 sjtu 的深红色」。砖红还认得出是红，但不再是交大的标准色
2. **守望先锋橙收成沙杏**：同上，橙色的游戏感弱了
3. **深色模式偏蓝**：从夜景取的深蓝灰，比原来的中性黑暖一点也蓝一点
4. **山形记号**：每个区块标题都有，可能显得重复
