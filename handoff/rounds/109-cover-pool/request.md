# 109 默认封面图库（官方图）

## 背景

用户 2026-10-03 先要我照守望先锋英雄形象画封面 SVG（「每个英雄都画几张……不同英雄组合场景也多画一些……也要动态的」）。我画了五张剪影样张（没进仓库），用户说：

> 这个太粗糙了。需要你对着官网或者游戏截图复刻的

我说明了两点：手写 SVG 对着参考描也只能到「轮廓准确的剪影」；照官方图一比一描出来属于暴雪美术的复制品，按设计「仓库不收录暴雪素材」不能进公开仓库。给了三个方向，用户选了**官方图库**：

> 管理员在后台上传一批官方壁纸、游戏截图当「默认封面图库」，没传封面的文章和赛事按编号自动取一张……画面就是游戏本身，动态效果用缓慢推拉镜头……图存在服务器上、不进仓库

## 本轮范围

**做**（先改设计 13.2.5，记 v6.7）：

1. Wagtail 图片里一个集合「默认封面」（`init_site` 建好）；管理员往里上传官方壁纸、截图
2. 文章、赛事没有封面，内战（没有封面字段）的横幅，按编号从图库取一张（`(ID + 偏移) mod 张数`，偏移和占位图一样），同一个对象永远是同一张；图库空着时照旧用占位图
3. 取出来的图缓慢推拉（放大一点、慢慢平移，四种方向和节奏按编号轮换），减少动态效果时不动；上传的封面、占位图不受影响
4. 一页只查一次图库（连缩略图），列表再长也不多查
5. 图库里加图、删图、把图移进移出这个集合时，全站重新生成
6. 演示站：图库要有官方图才看得到效果，需要从官网下载，先问用户

**不做**：按英雄、地图打标签挑图（以后）；分享图（仍是全站默认分享图）。

## 验证

测试：取图规则、空图库回退、推拉只给图库里的图、一页一次查询、图库变化触发全站生成、`init_site` 建集合、模板里不再直接用占位图滤镜；变异逐条改坏。

## 验收标准

`AGENTS.md`「常用命令」那组全绿；变异全部被抓到；推送 `main`，CI 绿。
