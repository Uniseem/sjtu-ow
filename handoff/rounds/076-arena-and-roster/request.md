# 076 赛场和名册

## 背景

074 定了设计体系，075 改完首页和内容页。本轮改「赛场」这一侧和成员名册：赛事列表与详情、内战列表与详情（含报名表单）、战队列表与主页（含入队按钮）、成员展示。

## 本轮范围

**做**：

1. 赛事列表（13.2.8「赛场列表」）：深色栏目头带各阶段数量；报名中、即将开放用票根（带已通过的队数）；已截止、已结束用紧凑表格
2. 赛事详情（「赛场详情」）：深色栏目头（状态、标签、标题、简介、关键事实条、报名入口占位）；主栏封面、说明、已通过的队伍、个人报名；侧栏资料表、相关文章
3. 内战列表：深色栏目头带数量；即将开始的用票根（名额格）、已结束的用表格
4. 内战详情：深色栏目头（状态、规格、开始时间、关键事实、报名占位）；主栏说明、各位置人数、报名名单；报名表单的位置改成 `c-choice`
5. 战队列表：深色栏目头（创建战队）；标签条筛选；图块墙（人数 / 上限、招募中）
6. 战队主页：深色栏目头（大队标、队名、成立时间、队长、名额格、入队占位）；主栏简介、成员表、参赛记录；侧栏资料表
7. 成员展示（「名册」）：分组目录、每组名片网格、全部成员编号名册（`001` 起）
8. 已通过队数、报名人数的统计挪进 `tournaments.services`、`scrims.services`，首页和列表页共用

**不做**：报名表单页、个人报名页、报名详情、战队创建 / 申请 / 管理、个人中心、登录注册（077）；业务规则。

## 验收标准

- 整组检查全绿
- 新规则有测试并做变异：赛事列表按阶段分两种样式、各阶段数量；详情页关键事实；内战列表的名额格数字；成员名册编号按加入先后；战队列表的人数 / 上限；战队主页成立时间和队长
- 1280 和 390 截图：赛事列表与详情（未登录、队长、散人）、内战列表与详情（未登录、已报名）、战队列表与主页、成员展示
