# 154 后台手册

## 背景

继续自主推进。以接手的社团干部的身份：下学期换届，新的赛事管理员、内战管理员、内容编辑不一定是开发者。后台功能这几十轮加了很多（发布和群发、报名审核、编队、分队、改期通知、内容审核、要求作者修改、头像审核、待办……），却没有一份「我该做什么、在哪儿做」的说明。Wagtail 自带的「帮助」是英文的通用编辑指南，也只给超级管理员和内容编辑。

## 本轮范围

1. `core/admin_manual.py`：按身份分五部分（赛事管理员、内战管理员、内容编辑、认证作者、超级管理员），每部分几步「做什么、在哪儿、会发生什么」，每步可以带一个真实入口的链接
2. 后台左侧菜单「后台手册」（`/admin/manual/`）：只显示和自己身份有关的部分；纯投稿者没有这一项，打开地址也被拒
3. 设计 14.1（v6.47）；README

## 验证

测试：各身份看到哪几部分（超级管理员四部分）；赛事管理员的首页菜单有入口、页面只有赛事部分、步骤链接对；投稿者没有菜单、打开被拒；超级管理员打开时所有链接都能解析（否则页面会报错）。变异逐条改坏。

## 验收标准

测试机上整组检查全绿；变异全部被抓到；推送 `main`，CI 绿；演示站升级。
