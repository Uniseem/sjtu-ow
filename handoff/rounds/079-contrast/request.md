# 079 文字和控件的对比度

## 背景

078 写 REVIEW-GUIDE 时把颜色令牌的对比度算了一遍：第三级文字色 `ink-3`（`#847C7A`）在页面底色上 3.75:1、凹陷底色上 3.5:1，不到 WCAG 2.1 AA 对正文的 4.5:1（1.4.3）。设计 13.2.3 写的「只用于 14px 以上的非关键文字」不成立：14px 不算 WCAG 的大字号，实际也用在日期、列表副行、评论署名行、占位文字、表格序号上，有的是 12px。

接着查同一件事时又发现两处：

- **表单控件的边框**：输入框、复选框、单选、选择块用 `line-strong`（`#B6B0AE`），在白底上 2.14:1、页面底色上 1.97:1，不到 WCAG 对界面元素边界要求的 3:1（1.4.11）
- **有 8 处颜色没走令牌**：深色区块上的第三级文字和强线、深色上的三种状态色，直接写了色值，违反 13.2.3「所有颜色只在 `@theme` 里定义一次」，也就没法和别的令牌一起检查

## 本轮范围

**做**：

1. 设计 13.2.3：`ink-3` 改成 `#726A68`；新增 `control`（控件边框）、`night-ink-3`、`night-line-strong`、`night-control`、`ok-bright`、`warn-bright`、`info-bright`；写明对比度规则和必须达标的组合表
2. `input.css`：令牌照改；新增语调变量 `--tone-control`，深色区块里翻转；输入框、下拉、文本框、复选框、单选、选择块、页头和抽屉里的搜索框的边框改用它；8 处写死的色值换成令牌
3. `static/css/error.css`：同步 `ink-3`（已有测试要求两边一致）
4. 测试：从 `input.css` 读令牌，按设计的组合表逐对算对比度；`@theme` 以外不能出现色值；表单控件的边框用 `--tone-control`
5. 样张页、截图看一遍（控件边框变深，页面整体观感要确认）

**不做**：换主色、改其他令牌；装饰性的线（`line`、`line-strong` 用在标签、名额格、票根虚线上）不承担识别，不要求 3:1。

## 验收标准

- 整组检查全绿；新规则各有测试并做变异
- 截图对比改前改后
