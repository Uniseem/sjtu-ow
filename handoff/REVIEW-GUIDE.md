# 独立复核指南（008–037）

写给做独立复核的人（用户计划交给 Grok）。

30 轮各自的 `request.md` 末尾有自己的复核清单，`report.md` 有验收输出，`review.md` 有实现方的自查结论。**但 30 轮逐个读一遍成本很高，而且平均用力等于没有重点。**

这份文件的作用是指路：**哪里最可能还有问题，以及为什么这么判断。**

## 怎么用

1. 先读这份
2. 按下面的优先级挑着查，每条都写明了「怎么验」
3. 结论追加到对应轮次的 `review.md`
4. 不同意实现方的判断时，直接说——下面「实现方的主观取舍」那节就是专门列出来给你推翻的

## 一条重要的前提

**实现方（Claude）的自查不能替代独立复核。** 这个 session 里自查找到了 20 多个真问题，但也有这些情况：

- **018 轮**：我说「设计 11.4 的错误码总表漏了两个码」，挂成待用户拍板的问题两轮。**实际是我看错了章节**（表在 11.10，两个码都在）。030 轮才发现。
- **023 轮**：我把性能目标判为「未验证，要等真机」。**034 轮推翻**——服务端处理时间和查询数本地就能量，一量就发现赛事详情页有 N+1（200 支队时 105 次查询）。
- **034 轮**：刚推翻完 023，自己的报告里又写「并发要等试运行」。**035 轮再次推翻**。同一个毛病连着两轮。

**我的「未验证」和「不影响」都值得你再问一遍。** 036 轮系统翻了一次，7 条里 5 条不该挂着。

## 优先级 1：本 session 修过的地方

这些地方刚改过，是最可能有新问题的地方。而且它们之所以有问题，往往说明那一块的测试本来就弱。

| 查什么 | 出处 | 怎么验 |
|---|---|---|
| **字体切片可复现** | 023 A1 | 同一个字体连切两次，内容哈希必须一样。`recalcTimestamp=False` 是关键。**这个 bug 从 013 轮潜伏到 023 轮，表现为「偶发测试失败」** |
| **报名状态机的越权** | 018 A1/A2 | 上游在 `local` 模式能不能改状态？两级审核能不能被上游跳过？033 轮把设计 8.5 整张表逐格测了，但你可以自己构造几个组合试 |
| **备份备的是哪个文件** | 022 A1 | `settings.DATABASE_PATH` 和 `connection.settings_dict["NAME"]` 不一定相同。测试环境下就不同 |
| **恢复的顺序** | 022 A2 | 先复制数据库再删 WAL 会让恢复静默失败。把顺序改回去跑测试，应该红 |
| **邮件主题前缀** | 030 | `core.mail` 会统一加前缀，应用层写裸主题。检查有没有新的通知又自己加了一遍 |
| **赛事详情页的查询数** | 034 | 造 200 支通过审核的战队，看查询数是不是恒定 |

## 优先级 2：我自己认下的、测试不够强的地方

这个 session 里**五次**发现「绿灯的测试其实没在测该测的东西」：

| 轮次 | 表面上在验什么 | 实际上验了什么 |
|---|---|---|
| 019 | 接口文档页能用 | 服务端没崩（返回 200，页面是空白的） |
| 021 | 剪枝没改变最优解 | **一个随机种子**下没改变 |
| 023 | 首页体积不超预算 | HTML 不超预算（静态资源全 404 被跳过了） |
| 026 | 邮件主题对 | 主题里有活动标题（前缀重复了也通过） |
| 029 | 地址存在 | `resolve()` 没抛异常——**而 Wagtail 兜底路由让它永远不抛** |

**建议的查法**：挑几条关键测试，把对应的实现改坏，看测试会不会红。这是我后期每轮都做的（「变异测试」），但前期（008–017）没有系统做过。

**039 轮我自己先试了 14 个变异点**（原本想留给你，但那个理由站不住——变异测试的结果是机械的，不受实现方倾向影响）。结果：

- 11 个被抓到
- **3 个连全量回归都抓不到**，已记录在 `039-mutation-sweep/report.md`：预渲染的 Set-Cookie 闸、解散战队仍可申请入队、签名比对不是常数时间
- 另有 2 个是被本 session 后期加的测试救的，说明 008–017 当初确实没覆盖

**14 个远不是全部。** 这条建议仍然成立，只是起点比原来高一些。

## 优先级 3：实现方的主观取舍（欢迎推翻）

这些是我自己定的，不是设计写的，也不是用户定的：

| 取舍 | 出处 | 我的理由 | 可以质疑的点 |
|---|---|---|---|
| 备份加密用 Fernet 不用 age | 031 | `cryptography` 已是依赖 | 设计原话是「比如用 age」；Fernet 整个文件读进内存，media 大了要改 |
| 备份加密密钥放环境变量不放后台 | 031 | 放数据库等于把钥匙锁在它保护的备份里 | 用户说的是「管理员在后台可以设置」，我只把桶的凭据放了后台 |
| 本地备份不加密 | 031 | 本地备份是给「手滑了马上恢复」用的 | |
| 满员的队伍拒绝拖入，而不是放进去标红 | 032 | 屏幕上永远是能保存的状态 | |
| 缓冲区的人保存后 `is_selected` 保留 | 032 | 清掉的话保存后人就从板子上消失了 | |
| `optimize_db` 检查点失败只警告 | 022 | 04:30 worker 可能正在写 | |
| AI 审核记录「已处理」= 状态不是 `pending` | 024 | 状态枚举本身就是答案 | 我没问用户就定了 |
